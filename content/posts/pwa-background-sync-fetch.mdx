# 🔔 PWA: Push Notifications و Notification API (سیستم اعلان کامل)

**💡 مفهوم کلیدی**  
سه API مرتبط برای سیستم اعلان کامل:
- **Notification API**: نمایش اعلان محلی (وقتی اپ بازه)
- **Push Notifications**: دریافت اعلان از سرور (حتی وقتی اپ بسته‌ست)
- **Notification Actions**: دکمه‌های تعاملی داخل اعلان (مثل "پاسخ"، "بایگانی"، "حذف")

این یعنی PWA شما می‌تونه مثل اپ‌های بومی (WhatsApp، Telegram) اعلان بفرسته، دکمه‌های تعاملی داشته باشه و حتی وقتی کاربر اپ رو نبسته، واکنش نشون بده.

**⚠️ دام رایج**

**Notification API:**
- فراموش کردن `Notification.requestPermission()` (بدون مجوز کار نمی‌کنه!).
- عدم بررسی `Notification.permission` قبل از نمایش.
- استفاده بدون user gesture (بعضی مرورگرها بلاک می‌کنن!).
- عدم ارائه‌ی راه غیرفعال‌سازی به کاربر.

**Push Notifications:**
- فراموش کردن VAPID keys (بدون اون سرور نمی‌تونه push بفرسته!).
- عدم مدیریت `push` event در Service Worker.
- عدم ذخیره subscription در سرور.
- فراموش کردن HTTPS (Push فقط روی HTTPS کار می‌کنه!).

**Notification Actions:**
- فراموش کردن `actions` در options.
- عدم مدیریت `notificationclick` event در Service Worker.
- عدم استفاده از `tag` برای جلوگیری از اعلان‌های تکراری.

**📏 وضعیت پشتیبانی مرورگرها**

| قابلیت                  | Chrome | Edge | Firefox | Safari | iOS Safari |
|-------------------------|--------|------|---------|--------|------------|
| Notification API        | ✅     | ✅   | ✅      | ✅     | ✅ (16.4+) |
| Push Notifications      | ✅     | ✅   | ✅      | ❌     | ✅ (16.4+) |
| Notification Actions    | ✅     | ✅   | ✅      | ❌     | ❌         |

> ⚠️ **نکته حیاتی**: iOS 16.4+ از Push Notifications پشتیبانی می‌کنه، ولی فقط وقتی PWA به هوم اسکرین اضافه شده باشه.

## 🔐 بخش اول: مدیریت مجوزها

### ۱. هوک مدیریت Permission

```jsx
// hooks/useNotificationPermission.js
import { useState, useEffect, useCallback } from 'react';

export function useNotificationPermission() {
  const [permission, setPermission] = useState('default'); // default | granted | denied
  const [isSupported, setIsSupported] = useState(false);

  useEffect(() => {
    setIsSupported('Notification' in window);
    
    if ('Notification' in window) {
      setPermission(Notification.permission);
    }
  }, []);

  // ✅ درخواست مجوز
  const requestPermission = useCallback(async () => {
    if (!isSupported) {
      console.warn('Notification API not supported');
      return false;
    }

    try {
      const result = await Notification.requestPermission();
      setPermission(result);
      return result === 'granted';
    } catch (error) {
      console.error('Failed to request permission:', error);
      return false;
    }
  }, [isSupported]);

  return {
    isSupported,
    permission,
    requestPermission,
    isGranted: permission === 'granted',
    isDenied: permission === 'denied',
  };
}
```

### ۳. هوک نمایش اعلان محلی

```jsx
// hooks/useLocalNotification.js
import { useCallback } from 'react';
import { useNotificationPermission } from './useNotificationPermission';

export function useLocalNotification() {
  const { isGranted, requestPermission } = useNotificationPermission();

  // ✅ نمایش اعلان محلی
  const showNotification = useCallback(async (title, options = {}) => {
    // ✅ بررسی مجوز
    if (!isGranted) {
      const granted = await requestPermission();
      if (!granted) {
        console.warn('Notification permission denied');
        return false;
      }
    }

    try {
      const notification = new Notification(title, {
        body: options.body || '',
        icon: options.icon || '/icons/icon-192.png',
        badge: options.badge || '/icons/badge-72.png',
        tag: options.tag || `notification-${Date.now()}`,
        requireInteraction: options.requireInteraction || false,
        silent: options.silent || false,
        vibrate: options.vibrate || [200, 100, 200],
        data: options.data || {},
        ...options,
      });

      // ✅ کلیک روی اعلان
      notification.onclick = (event) => {
        event.preventDefault();
        window.focus();
        notification.close();

        // ✅ ناوبری به صفحه مناسب
        if (options.data?.url) {
          window.location.href = options.data.url;
        }
      };

      // ✅ بستن خودکار بعد از ۵ ثانیه (اگه requireInteraction فعال نباشه)
      if (!options.requireInteraction) {
        setTimeout(() => notification.close(), 5000);
      }

      return true;
    } catch (error) {
      console.error('Failed to show notification:', error);
      return false;
    }
  }, [isGranted, requestPermission]);

  return { showNotification };
}

// ✅ استفاده:
function LocalNotificationExample() {
  const { showNotification } = useLocalNotification();

  const handleShow = async () => {
    await showNotification('پیام جدید', {

      icon: '/icons/icon-192.png',
      badge: '/icons/badge-72.png',
      tag: 'message',
      data: { url: '/messages' },
      vibrate: [200, 100, 200],
    });
  };

  return (
    <button onClick={handleShow} className="bg-blue-600 text-white px-4 py-2 rounded">
      نمایش اعلان تست
    </button>
  );
}
```

## 📡 بخش سوم: Push Notifications (اعلان از سرور)

### ۴. هوک مدیریت Push Subscription

```jsx
// hooks/usePushSubscription.js
import { useState, useEffect, useCallback } from 'react';
import { useNotificationPermission } from './useNotificationPermission';

// ✅ VAPID public key (از سرور بگیر)
const VAPID_PUBLIC_KEY = 'YOUR_VAPID_PUBLIC_KEY';

export function usePushSubscription() {
  const { isGranted, requestPermission } = useNotificationPermission();
  const [subscription, setSubscription] = useState(null);
  const [isSubscribed, setIsSubscribed] = useState(false);

  // ✅ تبدیل VAPID key به Uint8Array
  const urlBase64ToUint8Array = (base64String) => {
    const padding = '='.repeat((4 - (base64String.length % 4)) % 4);
    const base64 = (base64String + padding).replace(/-/g, '+').replace(/_/g, '/');
    const rawData = window.atob(base64);
    const outputArray = new Uint8Array(rawData.length);
    for (let i = 0; i < rawData.length; ++i) {
      outputArray[i] = rawData.charCodeAt(i);
    }
    return outputArray;
  };

  // ✅ ثبت subscription
  const subscribe = useCallback(async () => {
    if (!isGranted) {
      const granted = await requestPermission();
      if (!granted) return null;
    }

    try {
      const registration = await navigator.serviceWorker.ready;
      
      // ✅ بررسی subscription قبلی
      let sub = await registration.pushManager.getSubscription();
      
      if (!sub) {
        // ✅ ساخت subscription جدید
        sub = await registration.pushManager.subscribe({
          userVisibleOnly: true,
          applicationServerKey: urlBase64ToUint8Array(VAPID_PUBLIC_KEY),
        });
      }

      setSubscription(sub);
      setIsSubscribed(true);

      // ✅ ارسال subscription به سرور
      await fetch('/api/push/subscribe', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(sub),
      });

      console.log('✅ Subscribed to push notifications');
      return sub;
    } catch (error) {
      console.error('Failed to subscribe:', error);
      return null;
    }
  }, [isGranted, requestPermission]);

  // ✅ لغو subscription
  const unsubscribe = useCallback(async () => {
    if (!subscription) return false;

    try {
      await subscription.unsubscribe();
      
      // ✅ اطلاع به سرور
      await fetch('/api/push/unsubscribe', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ endpoint: subscription.endpoint }),
      });

      setSubscription(null);
      setIsSubscribed(false);
      console.log('✅ Unsubscribed from push notifications');
      return true;
    } catch (error) {
      console.error('Failed to unsubscribe:', error);
      return false;
    }
  }, [subscription]);

  // ✅ بررسی subscription هنگام لود
  useEffect(() => {
    const checkSubscription = async () => {
      if (!isGranted) return;

      const registration = await navigator.serviceWorker.ready;
      const sub = await registration.pushManager.getSubscription();
      
      if (sub) {
        setSubscription(sub);
        setIsSubscribed(true);
      }
    };

    checkSubscription();
  }, [isGranted]);

  return {
    subscription,
    isSubscribed,
    subscribe,
    unsubscribe,
  };
}
```

### ۶. Service Worker برای Push

```js
// public/sw.js

// ✅ دریافت push notification
self.addEventListener('push', (event) => {
  if (!event.data) return;

  const data = event.data.json();

  const options = {
    body: data.body || '',
    icon: data.icon || '/icons/icon-192.png',
    badge: data.badge || '/icons/badge-72.png',
    tag: data.tag || `push-${Date.now()}`,
    requireInteraction: data.requireInteraction || false,
    silent: data.silent || false,
    vibrate: data.vibrate || [200, 100, 200],
    data: data.data || {},
    
    // ✅ Notification Actions
    actions: data.actions || [
      {
        action: 'open',
        title: 'باز کردن',
        icon: '/icons/action-open.png',
      },
      {
        action: 'dismiss',
        title: 'بستن',
        icon: '/icons/action-dismiss.png',
      },
    ],
  };

  event.waitUntil(
    self.registration.showNotification(data.title || 'اعلان جدید', options)
  );
});

// ✅ کلیک روی اعلان
self.addEventListener('notificationclick', (event) => {
  const notification = event.notification;
  const action = event.action;
  const data = notification.data;

  notification.close();

  event.waitUntil(
    (async () => {
      // ✅ مدیریت action‌های مختلف
      if (action === 'dismiss') {
        // ✅ فقط بستن اعلان
        return;
      }

      if (action === 'reply') {
        // ✅ باز کردن صفحه پاسخ
        const url = data.replyUrl || '/messages';
        await openWindow(url);
        return;
      }

      if (action === 'archive') {
        // ✅ بایگانی کردن
        await fetch('/api/messages/archive', {
          method: 'POST',
          body: JSON.stringify({ messageId: data.messageId }),
        });
        return;
      }

      // ✅ action پیش‌فرض: باز کردن صفحه
      const url = data.url || '/';
      await openWindow(url);
    })()
  );
});

// ✅ باز کردن یا focus کردن window
async function openWindow(url) {
  const clients = await self.clients.matchAll({ type: 'window', includeUncontrolled: true });
  
  // ✅ اگه window بازه، focus کن
  for (const client of clients) {
    if (client.url === self.location.origin + url) {
      return client.focus();
    }
  }

  // ✅ اگه باز نیست، باز کن
  return self.clients.openWindow(url);
}

// ✅ بستن اعلان
self.addEventListener('notificationclose', (event) => {
  const notification = event.notification;
  const data = notification.data;

  // ✅ ارسال analytics
  console.log('Notification closed:', data);
});
```

# 🔄 PWA: Background Sync و پردازش در پس‌زمینه

**💡 مفهوم کلیدی**  
چهار قابلیت کلیدی برای کار در پس‌زمینه:
- **Background Sync**: sync کردن داده‌ها وقتی شبکه برمی‌گرده (مثل ارسال پیام‌های صف‌شده)
- **Periodic Background Sync**: اجراهای دوره‌ای در پس‌زمینه (مثل بروزرسانی محتوا)
- **Background Fetch**: دانلود فایل‌های بزرگ در پس‌زمینه (حتی وقتی اپ بسته‌ست)
- **Service Worker Lifecycle Events**: مدیریت چرخه‌ی حیات SW

این یعنی PWA شما می‌تونه مثل اپ‌های بومی کار کنه: حتی وقتی شبکه قطعه یا اپ بسته‌ست، کارها رو انجام بده.

**⚠️ دام رایج**

**Background Sync:**
- فراموش کردن `registration.sync.register()` در user gesture.
- عدم مدیریت `sync` event در Service Worker.
- عدم بررسی `lastChance` (آخرین فرصت قبل از لغو).

**Periodic Background Sync:**
- فراموش کردن `periodicsync` event.
- عدم تنظیم `minInterval` (حداقل فاصله بین اجراها).
- نادیده گرفتن اینکه نیاز به Engagement Score داره.

**Background Fetch:**
- فراموش کردن `backgroundFetch.register()`.
- عدم مدیریت `backgroundfetchsuccess` و `backgroundfetchfailure`.
- عدم نمایش progress به کاربر.

**📏 وضعیت پشتیبانی مرورگرها**

| قابلیت                     | Chrome | Edge | Firefox | Safari | iOS Safari |
|----------------------------|--------|------|---------|--------|------------|
| Background Sync            | ✅     | ✅   | ❌      | ❌     | ❌         |
| Periodic Background Sync   | ✅     | ✅   | ❌      | ❌     | ❌         |
| Background Fetch           | ✅     | ✅   | ❌      | ❌     | ❌         |
| SW Lifecycle Events        | ✅     | ✅   | ✅      | ✅     | ✅         |

> ⚠️ **نکته حیاتی**: Background Sync و Periodic Sync فقط در مرورگرهای **Chromium-based** کار می‌کنن. iOS و Firefox پشتیبانی نمی‌کنن.

## 🔄 بخش اول: Background Sync (sync یکباره)

### ۱. هوک ثبت Background Sync

```jsx
// hooks/useBackgroundSync.js
import { useState, useCallback } from 'react';

export function useBackgroundSync() {
  const [isSupported, setIsSupported] = useState(false);
  const [isRegistered, setIsRegistered] = useState(false);

  useState(() => {
    setIsSupported('serviceWorker' in navigator && 'SyncManager' in window);
  }, []);

  // ✅ ثبت sync task
  const registerSync = useCallback(async (tag, data = {}) => {
    if (!isSupported) {
      console.warn('Background Sync not supported');
      return false;
    }

    try {
      const registration = await navigator.serviceWorker.ready;
      
      // ✅ ذخیره داده در IndexedDB (چون SW به DOM دسترسی نداره)
      await saveToQueue(tag, data);
      
      // ✅ ثبت sync task
      await registration.sync.register(tag);
      setIsRegistered(true);
      
      console.log(`✅ Background sync registered: ${tag}`);
      return true;
    } catch (error) {
      console.error('Failed to register sync:', error);
      return false;
    }
  }, [isSupported]);

  // ✅ ذخیره در IndexedDB
  const saveToQueue = async (tag, data) => {
    const db = await openDB('sync-queue', 1, {
      upgrade(db) {
        if (!db.objectStoreNames.contains('tasks')) {
          db.createObjectStore('tasks', { keyPath: 'id', autoIncrement: true });
        }
      },
    });

    await db.add('tasks', {
      tag,
      data,
      timestamp: Date.now(),
    });
  };

  return { isSupported, isRegistered, registerSync };
}
```

```js
self.addEventListener('sync', (event) => {
  if (event.tag === 'sync-messages') {

  }

  if (event.tag === 'sync-orders') {
    event.waitUntil(syncOrders());

// ✅ sync پیام‌ها
async function syncMessages() {
  const db = await openDB('sync-queue', 1);
  const tasks = await db.getAllFromIndex('tasks', 'by-tag', 'sync-messages');

  for (const task of tasks) {
    try {
      // ✅ ارسال به سرور
      const response = await fetch('/api/messages/send', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(task.data),
      });

      if (response.ok) {
        // ✅ حذف از queue
        await db.delete('tasks', task.id);
        console.log(`✅ Message synced: ${task.id}`);
      }
    } catch (error) {
      console.error(`Failed to sync message ${task.id}:`, error);
      // ✅ اگر شبکه هنوز قطعه، task می‌مونه و دوباره تلاش می‌کنه
    }
  }
}

// ✅ sync سفارش‌ها
async function syncOrders() {
  const db = await openDB('sync-queue', 1);
  const tasks = await db.getAllFromIndex('tasks', 'by-tag', 'sync-orders');

  for (const task of tasks) {
    try {
      const response = await fetch('/api/orders/create', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(task.data),
      });

      if (response.ok) {
        await db.delete('tasks', task.id);
        console.log(`✅ Order synced: ${task.id}`);
      }
    } catch (error) {
      console.error(`Failed to sync order ${task.id}:`, error);
    }
  }
}
```

### ۳. کامپوننت ارسال پیام آفلاین

```jsx
// components/OfflineMessageSender.jsx
import { useState } from 'react';
import { useBackgroundSync } from '@/hooks/useBackgroundSync';

export function OfflineMessageSender() {
  const { isSupported, registerSync } = useBackgroundSync();
  const [message, setMessage] = useState('');
  const [sending, setSending] = useState(false);

  const handleSend = async () => {
    if (!message.trim()) return;

    setSending(true);

    const success = await registerSync('sync-messages', {
      text: message,
      timestamp: Date.now(),
    });

    if (success) {
      setMessage('');
      alert('✅ پیام در صف ارسال قرار گرفت. وقتی شبکه وصل شد، ارسال می‌شه.');
    } else {
      alert('❌ خطا در ثبت پیام');
    }

    setSending(false);
  };

  if (!isSupported) {
    return (
      <div className="p-4 bg-yellow-50 border border-yellow-200 rounded-lg">
        <p className="text-sm text-yellow-800">
          ⚠️ Background Sync در این مرورگر پشتیبانی نمیشه.
        </p>
      </div>
    );
  }

  return (
    <div className="space-y-3">
      <textarea
        value={message}
        onChange={(e) => setMessage(e.target.value)}
        placeholder="پیام خود را بنویسید..."
        rows={3}
        className="w-full p-3 border border-gray-300 rounded-lg"
      />
      <button
        onClick={handleSend}
        disabled={sending || !message.trim()}
        className="w-full bg-blue-600 text-white px-4 py-2 rounded-lg hover:bg-blue-700 disabled:opacity-50"
      >
        {sending ? 'در حال ثبت...' : 'ارسال پیام'}
      </button>
    </div>
  );
}
```

### ۴. هوک ثبت Periodic Sync

```jsx
// hooks/usePeriodicBackgroundSync.js
import { useState, useCallback } from 'react';

export function usePeriodicBackgroundSync() {
  const [isSupported, setIsSupported] = useState(false);
  const [isRegistered, setIsRegistered] = useState(false);

  useState(() => {
    setIsSupported(
      'serviceWorker' in navigator && 
      'periodicSync' in window.SyncManager.prototype
    );
  }, []);

  // ✅ ثبت periodic sync
  const registerPeriodicSync = useCallback(async (tag, minInterval = 3600000) => {
    if (!isSupported) {
      console.warn('Periodic Background Sync not supported');
      return false;
    }

    try {
      const registration = await navigator.serviceWorker.ready;
      
      // ✅ بررسی permission
      const status = await navigator.permissions.query({
        name: 'periodic-background-sync',
      });

      if (status.state !== 'granted') {
        console.warn('Periodic background sync permission not granted');
        return false;
      }

      // ✅ ثبت periodic sync
      await registration.periodicSync.register(tag, {
        minInterval: minInterval, // حداقل فاصله بین اجراها (میلی‌ثانیه)
      });

      setIsRegistered(true);
      console.log(`✅ Periodic sync registered: ${tag} (every ${minInterval / 1000}s)`);
      return true;
    } catch (error) {
      console.error('Failed to register periodic sync:', error);
      return false;
    }
  }, [isSupported]);

  // ✅ لغو periodic sync
  const unregisterPeriodicSync = useCallback(async (tag) => {
    try {
      const registration = await navigator.serviceWorker.ready;
      await registration.periodicSync.unregister(tag);
      setIsRegistered(false);
      console.log(`✅ Periodic sync unregistered: ${tag}`);
      return true;
    } catch (error) {
      console.error('Failed to unregister periodic sync:', error);
      return false;
    }
  }, []);

  return { isSupported, isRegistered, registerPeriodicSync, unregisterPeriodicSync };
}
```

```js
// public/sw.js

// ✅ مدیریت Periodic Background Sync
self.addEventListener('periodicsync', (event) => {
  if (event.tag === 'update-content') {
    event.waitUntil(updateContent());
  }

  if (event.tag === 'sync-analytics') {
    event.waitUntil(syncAnalytics());
  }
});

// ✅ بروزرسانی محتوا
async function updateContent() {
  try {
    // ✅ دریافت داده‌های جدید از سرور
    const response = await fetch('/api/content/latest');
    
    if (response.ok) {
      const data = await response.json();
      
      // ✅ ذخیره در cache
      const cache = await caches.open('content-v1');
      await cache.put('/api/content/latest', new Response(JSON.stringify(data)));
      
      console.log('✅ Content updated in background');
    }
  } catch (error) {
    console.error('Failed to update content:', error);
  }
}

// ✅ sync analytics
async function syncAnalytics() {
  const db = await openDB('analytics-queue', 1);
  const events = await db.getAll('events');

  if (events.length === 0) return;

  try {
    const response = await fetch('/api/analytics/batch', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ events }),
    });

    if (response.ok) {
      await db.clear('events');
      console.log(`✅ Synced ${events.length} analytics events`);
    }
  } catch (error) {
    console.error('Failed to sync analytics:', error);
  }
}
```

## 📥 بخش سوم: Background Fetch (دانلود فایل بزرگ)

### ۷. هوک Background Fetch

```jsx
// hooks/useBackgroundFetch.js
import { useState, useCallback } from 'react';

export function useBackgroundFetch() {
  const [isSupported, setIsSupported] = useState(false);
  const [activeFetches, setActiveFetches] = useState([]);

  useState(() => {
    setIsSupported('serviceWorker' in navigator && 'BackgroundFetchManager' in window);
  }, []);

  // ✅ ثبت background fetch
  const registerBackgroundFetch = useCallback(async (id, urls, options = {}) => {
    if (!isSupported) {
      console.warn('Background Fetch not supported');
      return false;
    }

    try {
      const registration = await navigator.serviceWorker.ready;
      
      const fetch = await registration.backgroundFetch.fetch(id, urls, {
        title: options.title || 'دانلود فایل',
        icons: options.icons || [{ src: '/icons/icon-192.png', sizes: '192x192' }],
        downloadTotal: options.downloadTotal || 0,
      });

      setActiveFetches((prev) => [...prev, { id, fetch }]);
      
      console.log(`✅ Background fetch registered: ${id}`);
      return true;
    } catch (error) {
      console.error('Failed to register background fetch:', error);
      return false;
    }
  }, [isSupported]);

  // ✅ لغو background fetch
  const abortBackgroundFetch = useCallback(async (id) => {
    try {
      const registration = await navigator.serviceWorker.ready;
      const fetch = await registration.backgroundFetch.get(id);
      
      if (fetch) {
        await fetch.abort();
        setActiveFetches((prev) => prev.filter((f) => f.id !== id));
        console.log(`✅ Background fetch aborted: ${id}`);
        return true;
      }
      return false;
    } catch (error) {
      console.error('Failed to abort background fetch:', error);
      return false;
    }
  }, []);

  return { isSupported, activeFetches, registerBackgroundFetch, abortBackgroundFetch };
}
```

```js
// ✅ مدیریت Background Fetch events
self.addEventListener('backgroundfetchsuccess', (event) => {
  event.waitUntil(handleFetchSuccess(event));
});

self.addEventListener('backgroundfetchfailure', (event) => {
  event.waitUntil(handleFetchFailure(event));
});

self.addEventListener('backgroundfetchabort', (event) => {
  console.log(`Background fetch aborted: ${event.tag}`);
});

self.addEventListener('backgroundfetchclick', (event) => {
  // ✅ کلیک روی notification دانلود
  event.waitUntil(
    self.clients.openWindow(`/downloads/${event.tag}`)
  );
});

// ✅ مدیریت موفقیت
async function handleFetchSuccess(event) {
  const db = await openDB('downloads', 1, {
    upgrade(db) {
      if (!db.objectStoreNames.contains('files')) {
        db.createObjectStore('files', { keyPath: 'id' });
      }
    },
  });

  // ✅ ذخیره فایل‌های دانلود شده
  for (const record of event.results) {
    const response = await record.responseReady;
    const blob = await response.blob();
    
    await db.put('files', {
      id: event.tag,
      url: record.request.url,
      blob,
      timestamp: Date.now(),
    });
  }

  console.log(`✅ Background fetch success: ${event.tag}`);
}

// ✅ مدیریت شکست
async function handleFetchFailure(event) {
  console.error(`❌ Background fetch failed: ${event.tag}`);
  
  // ✅ نمایش notification خطا
  await self.registration.showNotification('دانلود ناموفق', {
    body: `دانلود ${event.tag} با خطا مواجه شد`,
    icon: '/icons/icon-192.png',
  });
}
```

## 🔄 بخش چهارم: Service Worker Lifecycle Events

### ۱۰. مرور کامل Lifecycle Events

```js
// public/sw.js

// ✅ ۱. Install Event
self.addEventListener('install', (event) => {
  console.log('[SW] Installing...');
  
  event.waitUntil(
    (async () => {
      // ✅ cache کردن assets اولیه
      const cache = await caches.open('app-v1');
      await cache.addAll([
        '/',
        '/offline.html',
        '/styles.css',
        '/app.js',
      ]);
      
      console.log('[SW] Precaching complete');
    })()
  );
  
  // ✅ رفتن مستقیم به activate (بدون waiting)
  self.skipWaiting();
});

// ✅ ۲. Activate Event
self.addEventListener('activate', (event) => {
  console.log('[SW] Activating...');
  
  event.waitUntil(
    (async () => {
      // ✅ پاک کردن cache‌های قدیمی
      const keys = await caches.keys();
      await Promise.all(
        keys
          .filter((key) => key !== 'app-v1')
          .map((key) => caches.delete(key))
      );
      
      // ✅ takeover: کنترل همه‌ی کلاینت‌ها
      await self.clients.claim();
      
      console.log('[SW] Activated & claimed all clients');
    })()
  );
});

// ✅ ۳. Fetch Event
self.addEventListener('fetch', (event) => {
  // ✅ فقط درخواست‌های same-origin
  if (!event.request.url.startsWith(self.location.origin)) return;

  event.respondWith(
    (async () => {
      // ✅ Cache First strategy
      const cached = await caches.match(event.request);
      if (cached) {
        return cached;
      }

      // ✅ Network fallback
      try {
        const response = await fetch(event.request);
        
        // ✅ cache کردن پاسخ موفق
        if (response.ok) {
          const cache = await caches.open('app-v1');
          cache.put(event.request, response.clone());
        }
        
        return response;
      } catch (error) {
        // ✅ Offline fallback
        if (event.request.mode === 'navigate') {
          return caches.match('/offline.html');
        }
        throw error;
      }
    })()
  );
});

// ✅ ۴. Push Event
self.addEventListener('push', (event) => {
  if (!event.data) return;

  const data = event.data.json();

  event.waitUntil(
    self.registration.showNotification(data.title, {
      body: data.body,
      icon: '/icons/icon-192.png',
      badge: '/icons/badge-72.png',
      data: data.data,
    })
  );
});

// ✅ ۵. Sync Event (Background Sync)
self.addEventListener('sync', (event) => {
  if (event.tag === 'sync-messages') {
    event.waitUntil(syncMessages());
  }
});

// ✅ ۶. Periodic Sync Event
self.addEventListener('periodicsync', (event) => {
  if (event.tag === 'update-content') {
    event.waitUntil(updateContent());
  }
});

// ✅ ۷. Message Event (ارتباط با UI)
self.addEventListener('message', (event) => {
  if (event.data?.type === 'SKIP_WAITING') {
    self.skipWaiting();
  }
  
  if (event.data?.type === 'GET_VERSION') {
    event.source.postMessage({ type: 'VERSION', version: 'v1.0.0' });
  }
});
```
