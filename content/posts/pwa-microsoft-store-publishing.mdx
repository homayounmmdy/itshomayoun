# 🪟 PWA: انتشار در Microsoft Store به عنوان اپ ویندوز

**💡 مفهوم کلیدی**  
Microsoft Store یکی از بهترین راه‌ها برای توزیع PWA به عنوان **اپ ویندوز** هست. با استفاده از **PWABuilder** می‌تونی PWA رو به بسته‌ی **MSIX** تبدیل کنی و در Store منتشر کنی. مزایا:
- دسترسی به ۱ میلیارد کاربر ویندوز
- آپدیت خودکار
- یکپارچگی با Start Menu و Taskbar
- قابلیت نصب آفلاین
- بدون نیاز به Electron یا بسته‌بندی سنگین

**⚠️ دام رایج**  
- فراموش کردن `scope` و `start_url` درست در manifest (Store رد می‌کنه!).
- عدم ارائه‌ی آیکون‌های با سایز مناسب (50×50 تا 1240×1240).
- فراموش کردن HTTPS (الزامی!).
- عدم تست MSIX قبل از سابمیت.
- فراموش کردن `package.appxmanifest` سفارشی.
- عدم تنظیم `background_color` و `theme_color`.
- نادیده گرفتن سیاست‌های Store (مثل محتوای تکراری).
- عدم استفاده از `PWABuilder` برای تولید خودکار.

**📏 پیش‌نیازها**

| مورد                          | توضیح                                              |
|-------------------------------|----------------------------------------------------|
| PWA با manifest معتبر         | name, short_name, icons, start_url, display       |
| HTTPS                         | الزامی (به جز localhost برای تست)                 |
| Service Worker                | برای کار آفلاین                                   |
| آیکون‌های با سایزهای مختلف    | 50×50, 150×150, 44×44, 512×512                    |
| حساب Microsoft Partner Center  | هزینه‌ی ثبت‌نام یک‌باره: ۱۹ دلار (فردی) / ۹۹ دلار (شرکت) |
| PWABuilder                    | ابزار رسمی Microsoft برای بسته‌بندی                |

### ۲. بررسی آمادگی PWA

```jsx
// components/StoreReadinessCheck.jsx
import { useState, useEffect } from 'react';

export function StoreReadinessCheck() {
  const [checks, setChecks] = useState([]);

  useEffect(() => {
    const runChecks = async () => {
      const results = [];

      // ✅ بررسی HTTPS
      results.push({
        name: 'HTTPS',
        passed: window.location.protocol === 'https:',
        message: window.location.protocol === 'https:' 
          ? '✅ سایت روی HTTPS هست' 
          : '❌ سایت باید روی HTTPS باشه',
      });

      // ✅ بررسی manifest
      try {
        const response = await fetch('/manifest.json');
        const manifest = await response.json();
        
        results.push({
          name: 'Manifest',
          passed: !!manifest.name && !!manifest.start_url && manifest.icons?.length > 0,
          message: '✅ Manifest معتبر هست',
        });

        // ✅ بررسی آیکون‌ها
        const requiredSizes = ['44x44', '50x50', '150x150', '192x192', '512x512'];
        const iconSizes = manifest.icons?.map((i) => i.sizes) || [];
        const hasAllSizes = requiredSizes.every((size) => 
          iconSizes.some((s) => s.includes(size.split('x')[0]))
        );

        results.push({
          name: 'Icons',
          passed: hasAllSizes,
          message: hasAllSizes 
            ? '✅ همه‌ی سایزهای آیکون موجودن' 
            : '❌ بعضی سایزهای آیکون موجود نیستن',
        });
      } catch (error) {
        results.push({
          name: 'Manifest',
          passed: false,
          message: '❌ Manifest پیدا نشد',
        });
      }

      // ✅ بررسی Service Worker
      if ('serviceWorker' in navigator) {
        const registration = await navigator.serviceWorker.getRegistration();
        results.push({
          name: 'Service Worker',
          passed: !!registration,
          message: registration 
            ? '✅ Service Worker ثبت شده' 
            : '❌ Service Worker ثبت نشده',
        });
      }

      // ✅ بررسی display mode
      const isStandalone = window.matchMedia('(display-mode: standalone)').matches;
      results.push({
        name: 'Display Mode',
        passed: true,
        message: '✅ Display mode: standalone',
      });

      setChecks(results);
    };

    runChecks();
  }, []);

  const allPassed = checks.every((c) => c.passed);

  return (
    <div className="max-w-md mx-auto p-6 bg-white rounded-xl shadow-lg space-y-4">
      <h2 className="text-xl font-bold">
        {allPassed ? '✅ آماده‌ی انتشار' : '⚠️ نیاز به اصلاح'}
      </h2>

      <ul className="space-y-2">
        {checks.map((check, idx) => (
          <li
            key={idx}
            className={`p-3 rounded-lg border ${
              check.passed 
                ? 'bg-green-50 border-green-200' 
                : 'bg-red-50 border-red-200'
            }`}
          >
            <p className="font-medium text-sm">{check.name}</p>
            <p className="text-xs text-gray-600 mt-1">{check.message}</p>
          </li>
        ))}
      </ul>

      {allPassed && (
        <a
          href="https://www.pwabuilder.com/"
          target="_blank"
          rel="noopener noreferrer"
          className="block w-full bg-blue-600 text-white text-center px-6 py-3 rounded-lg hover:bg-blue-700 font-medium"
        >
          🚀 ادامه در PWABuilder
        </a>
      )}
    </div>
  );
}
```

## 📦 بخش دوم: بسته‌بندی با PWABuilder

### ۳. مراحل استفاده از PWABuilder

```markdown
## مراحل بسته‌بندی:

### ۱. ورود به PWABuilder
- برو به [pwabuilder.com](https://www.pwabuilder.com/)
- URL سایتت رو وارد کن
- PWABuilder manifest رو تحلیل می‌کنه

### ۲. بررسی امتیاز PWA
- PWABuilder امتیاز PWA رو نشون میده
- اگه کمتر از ۱۰۰ هست، مشکلات رو رفع کن

### ۳. انتخاب پلتفرم Windows
- روی "Package for Stores" کلیک کن
- پلتفرم "Windows" رو انتخاب کن

### ۴. تنظیمات بسته
- **Package Name**: نام یکتا (مثل `com.example.myapp`)
- **Publisher**: CN=YourName (از Partner Center می‌گیری)
- **Version**: 1.0.0.0
- **Icons**: آیکون‌های با سایزهای مختلف آپلود کن

### ۵. دانلود بسته
- PWABuilder یه فایل ZIP می‌ده
- شامل: `.msixbundle` و `StoreAssets`
```

### ۱۱. هوک تشخیص آپدیت

```jsx
// hooks/useStoreUpdate.js
import { useState, useEffect } from 'react';

export function useStoreUpdate() {
  const [currentVersion, setCurrentVersion] = useState(null);
  const [updateAvailable, setUpdateAvailable] = useState(false);

  useEffect(() => {
    // ✅ دریافت نسخه فعلی از Service Worker
    if ('serviceWorker' in navigator) {
      navigator.serviceWorker.ready.then((registration) => {
        if (registration.active) {
          registration.active.postMessage({ type: 'GET_VERSION' });
        }
      });

      navigator.serviceWorker.addEventListener('message', (event) => {
        if (event.data?.type === 'VERSION') {
          setCurrentVersion(event.data.version);
        }
      });
    }

    // ✅ بررسی آپدیت (هر ۲۴ ساعت)
    const checkUpdate = async () => {
      try {
        const response = await fetch('/api/version');
        const data = await response.json();
        
        if (currentVersion && data.version !== currentVersion) {
          setUpdateAvailable(true);
        }
      } catch (error) {
        console.error('Update check failed:', error);
      }
    };

    const interval = setInterval(checkUpdate, 24 * 60 * 60 * 1000);
    return () => clearInterval(interval);
  }, [currentVersion]);

  return { currentVersion, updateAvailable };
}
```
