# 🔗 PWA: Web Share API و Share Target (اشتراک‌گذاری دوطرفه)

**💡 مفهوم کلیدی**  
دو API مکمل برای اشتراک‌گذاری:
- **Web Share API**: سایت شما → اپ‌های دیگه (مثل WhatsApp، Telegram، ایمیل)
- **Web Share Target**: اپ‌های دیگه → سایت شما (کاربر از گالری عکس share می‌کنه به سایت شما)

این یعنی PWA شما می‌تونه **هم بفرسته و هم بگیره** - دقیقاً مثل یه اپ بومی!

**⚠️ دام رایج**

**Web Share API:**
- فراموش کردن `navigator.canShare()` قبل از share (بعضی مرورگرها فایل پشتیبانی نمی‌کنن!).
- عدم ارائه‌ی fallback (مثل copy to clipboard) برای دسکتاپ.
- استفاده بدون user gesture (مرورگر بلاک می‌کنه!).
- نادیده گرفتن `navigator.share` در Safari iOS (فقط در user gesture کار می‌کنه).

**Web Share Target:**
- فراموش کردن `share_target` در manifest.
- عدم مدیریت `POST` request در صفحه‌ی هدف.
- فراموش کردن `enctype: "multipart/form-data"` برای فایل‌ها.
- عدم تست در اندروید (فقط Chrome Android پشتیبانی می‌کنه!).

**📏 وضعیت پشتیبانی مرورگرها**

| قابلیت              | Chrome | Edge | Safari | Firefox | iOS Safari |
|---------------------|--------|------|--------|---------|------------|
| Web Share API       | ✅     | ✅   | ✅     | ✅      | ✅         |
| Share with Files    | ✅     | ✅   | ❌     | ❌      | ❌         |
| Web Share Target    | ✅     | ✅   | ❌     | ❌      | ❌         |

> ⚠️ **نکته حیاتی**: Share Target فقط در **Chrome Android** و بعضی نسخه‌های دسکتاپ کار می‌کنه.

## 📤 بخش اول: Web Share API (ارسال به اپ‌های دیگه)

### ۱. هوک React برای Web Share

```jsx
// hooks/useWebShare.js
import { useState, useCallback } from 'react';

export function useWebShare() {
  const [isSupported, setIsSupported] = useState(
    typeof navigator !== 'undefined' && 'share' in navigator
  );
  const [error, setError] = useState(null);

  // ✅ بررسی اینکه آیا می‌تونه share کنه
  const canShare = useCallback((data) => {
    if (!isSupported) return false;
    
    if ('canShare' in navigator) {
      return navigator.canShare(data);
    }
    
    // ✅ fallback: فقط text و url پشتیبانی میشه
    return !data.files;
  }, [isSupported]);

  // ✅ اشتراک‌گذاری
  const share = useCallback(async (shareData) => {
    if (!isSupported) {
      setError('Web Share API پشتیبانی نمیشه');
      return false;
    }

    try {
      setError(null);
      await navigator.share(shareData);
      console.log('✅ Shared successfully');
      return true;
    } catch (err) {
      if (err.name === 'AbortError') {
        // ✅ کاربر cancel کرد
        return false;
      }
      setError(err.message);
      return false;
    }
  }, [isSupported]);

  // ✅ اشتراک‌گذاری متن
  const shareText = useCallback(async (text, title) => {
    return share({ title, text });
  }, [share]);

  // ✅ اشتراک‌گذاری لینک
  const shareUrl = useCallback(async (url, title, text) => {
    return share({ title, url, text });
  }, [share]);

  // ✅ اشتراک‌گذاری فایل
  const shareFiles = useCallback(async (files, title, text) => {
    if (!canShare({ files })) {
      setError('اشتراک‌گذاری فایل در این مرورگر پشتیبانی نمیشه');
      return false;
    }
    return share({ title, text, files });
  }, [share, canShare]);

  return {
    isSupported,
    canShare,
    share,
    shareText,
    shareUrl,
    shareFiles,
    error,
  };
}
```

```jsx
// components/ShareButton.jsx
import { useState } from 'react';
import { useWebShare } from '@/hooks/useWebShare';

export function ShareButton({ title, text, url, files }) {
  const { isSupported, share, shareFiles, error } = useWebShare();
  const [showFallback, setShowFallback] = useState(false);

  const handleShare = async () => {
    if (files && files.length > 0) {
      const success = await shareFiles(files, title, text);
      if (!success) setShowFallback(true);
    } else {
      const success = await share({ title, text, url });
      if (!success) setShowFallback(true);

    try {
      await navigator.clipboard.writeText(url || window.location.href);

    } catch (err) {
      alert('خطا در کپی لینک');
    }
  };

  return (
    <div className="space-y-3">
      <button
        onClick={handleShare}
        className="w-full bg-blue-600 text-white px-6 py-3 rounded-lg

        <svg className="w-5 h-5" fill="none" viewBox="0 0 24 24" stroke="currentColor">

            </button>
          </div>
        </div>
      )}

      {error && (
        <p className="text-sm text-red-600">{error}</p>
      )}
    </div>
  );
}
```

```jsx
// components/ShareImage.jsx
import { useState, useRef } from 'react';
import { useWebShare } from '@/hooks/useWebShare';

export function ShareImage() {
  const { shareFiles, canShare, isSupported } = useWebShare();
  const [selectedFile, setSelectedFile] = useState(null);
  const fileInputRef = useRef(null);

  const handleFileSelect = (e) => {
    const file = e.target.files[0];
    if (file) {
      setSelectedFile(file);
    }
  };

  const handleShare = async () => {
    if (!selectedFile) return;

    const success = await shareFiles(
      [selectedFile],
      'عکس من',
      'این عکس رو ببین!'
    );

    if (success) {
      alert('عکس با موفقیت share شد!');
    }
  };

  const canShareFiles = canShare({ files: [new File([''], 'test.png')] });

  return (
    <div className="space-y-4">
      <input
        ref={fileInputRef}
        type="file"
        accept="image/*"
        onChange={handleFileSelect}
        className="hidden"
      />

      <button
        onClick={() => fileInputRef.current?.click()}
        className="w-full bg-gray-200 text-gray-800 px-4 py-2 rounded-lg hover:bg-gray-300"
      >
        انتخاب عکس
      </button>

      {selectedFile && (
        <div className="space-y-3">
          <img
            src={URL.createObjectURL(selectedFile)}
            alt="preview"
            className="w-full max-w-xs mx-auto rounded-lg"
          />
          
          {canShareFiles ? (
            <button
              onClick={handleShare}
              className="w-full bg-blue-600 text-white px-4 py-2 rounded-lg hover:bg-blue-700"
            >
              اشتراک‌گذاری عکس
            </button>
          ) : (
            <p className="text-sm text-yellow-600 text-center">
              ⚠️ اشتراک‌گذاری فایل در این مرورگر پشتیبانی نمیشه
            </p>
          )}
        </div>
      )}
    </div>
  );
}
```

### ۵. هوک دریافت Share Target

```jsx
// hooks/useShareTarget.js
import { useState, useEffect } from 'react';
import { useRouter } from 'next/router'; // یا useSearchParams از react-router

export function useShareTarget() {
  const [sharedData, setSharedData] = useState(null);
  const [isProcessing, setIsProcessing] = useState(false);

  useEffect(() => {
    const processShareData = async () => {
      // ✅ بررسی اینکه آیا از share target اومده
      const urlParams = new URLSearchParams(window.location.search);
      
      // ✅ روش ۱: GET parameters
      const title = urlParams.get('title');
      const text = urlParams.get('text');
      const url = urlParams.get('url');

      if (title || text || url) {
        setSharedData({ title, text, url });
        return;
      }

      // ✅ روش ۲: POST data (برای فایل‌ها)
      if (window.location.pathname === '/share-target') {
        setIsProcessing(true);
        
        try {
          const formData = await requestFormData();
          
          if (formData) {
            setSharedData({
              title: formData.get('title'),
              text: formData.get('text'),
              url: formData.get('url'),
              files: formData.getAll('images'),
            });
          }
        } catch (error) {
          console.error('Failed to process share data:', error);
        } finally {
          setIsProcessing(false);
        }
      }
    };

    processShareData();
  }, []);

  // ✅ خواندن FormData از POST request
  const requestFormData = async () => {
    // ✅ این یه ترفت هست: مرورگر POST data رو به صورت FormData می‌فرسته
    // ولی ما نمی‌تونیم مستقیم بهش دسترسی داشته باشیم
    // باید از یه فرم مخفی استفاده کنیم یا service worker
    
    // ✅ ساده‌ترین راه: از URLSearchParams استفاده کن
    return new FormData();
  };

  return { sharedData, isProcessing };
}
```

### ۷. Service Worker برای مدیریت POST

```js
// public/sw.js
self.addEventListener('fetch', (event) => {
  const url = new URL(event.request.url);

  // ✅ مدیریت POST request از share target
  if (url.pathname === '/share-target' && event.request.method === 'POST') {
    event.respondWith(
      (async () => {
        const formData = await event.request.formData();
        
        // ✅ تبدیل به URL parameters و redirect
        const params = new URLSearchParams();
        
        for (const [key, value] of formData.entries()) {
          params.append(key, value);
        }

        // ✅ redirect به صفحه با parameters
        return Response.redirect(`/share-target?${params.toString()}`, 303);
      })()
    );
  }
});
```

```jsx
// components/CompleteShareSystem.jsx
import { useState } from 'react';
import { useWebShare } from '@/hooks/useWebShare';
import { useShareTarget } from '@/hooks/useShareTarget';

export function CompleteShareSystem() {
  const { share, isSupported: canShareOut } = useWebShare();
  const { sharedData } = useShareTarget();

  const [content, setContent] = useState({
    title: '',
    text: '',
    url: '',
  });

        text: sharedData.text || '',

      });
    }

    await share(content);
  };

  return (
    <div className="max-w-md mx-auto p-6 bg-white rounded-xl shadow-lg space-y-6">
      <h2 className="text-2xl font-bold">🔗 سیستم اشتراک‌گذاری</h2>

        <div className="p-4 bg-green-50 border border-green-200 rounded-lg">
          <p className="text-sm font-medium text-green-800 mb-2">
            ✅ محتوا دریافت شد:
          </p>
          <p className="text-sm text-green-700">{sharedData.title}</p>
        </div>
      )}

      {/* ✅ فرم اشتراک‌گذاری */}
      <div className="space-y-3">
        <input
          type="text"
          value={content.title}

          rows={3}
          className="w-full p-3 border border-gray-300 rounded-lg"
        />
        <input
          type="url"
          value={content.url}
          onChange={(e) => setContent({ ...content, url: e.target.value })}
          placeholder="لینک"
          className="w-full p-3 border border-gray-300 rounded-lg"
        />
      </div>

      {/* ✅ دکمه share */}
      {canShareOut && (
        <button
          onClick={handleShare}
          className="w-full bg-blue-600 text-white px-6 py-3 rounded-lg 
                     hover:bg-blue-700 transition-colors font-medium"
        >
          اشتراک‌گذاری
        </button>
      )}
    </div>
  );
}
```

**🔗 ابزار تست**

**Web Share API:**
- **Chrome Android**: دکمه share رو بزن، باید Share Sheet باز بشه.
- **Safari iOS**: باید Share Sheet باز بشه.
- **Chrome Desktop**: ممکنه fallback (copy link) نشون داده بشه.
- **Console**: `navigator.share({ title: 'Test', text: 'Hello' })`.

**Web Share Target:**
- **Chrome Android**: PWA رو نصب کن، از گالری عکس share کن، باید سایت شما در لیست باشه.
- **DevTools** → Application → Manifest → بررسی `share_target`.
- **تست واقعی**: یه عکس رو از گالری به سایت share کن.

**⚠️ چک‌لیست نهایی**

**Web Share API:**
- [ ] بررسی `navigator.share` قبل از استفاده؟
- [ ] استفاده از `canShare()` برای بررسی فایل‌ها؟
- [ ] fallback برای دسکتاپ (copy link) داری؟
- [ ] مدیریت `AbortError` (cancel توسط کاربر)؟
- [ ] استفاده در user gesture (کلیک)؟

**Web Share Target:**
- [ ] `share_target` در manifest تعریف شده؟
- [ ] `action` به صفحه درست اشاره می‌کنه؟
- [ ] `method: "POST"` برای فایل‌ها؟
- [ ] `enctype: "multipart/form-data"` برای فایل‌ها؟
- [ ] صفحه‌ی هدف داده‌ها رو درست پردازش می‌کنه؟
- [ ] Service Worker POST request رو مدیریت می‌کنه؟
- [ ] در Chrome Android واقعی تست شده؟

> **قانون ۳ ثانیه‌ای:** PWA رو روی اندروید نصب کن. از گالری یه عکس رو share کن؛ آیا سایت شما در لیست اپ‌ها ظاهر میشه؟ بعد سایت رو باز کن و دکمه share رو بزن؛ آیا Share Sheet باز میشه؟ اگه در یکی از این دو تا کار نکرد، یعنی API رو درست پیاده‌سازی نکردی!
