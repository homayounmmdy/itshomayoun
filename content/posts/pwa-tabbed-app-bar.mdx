# 📑 PWA: Tabbed App Bar و تب‌های داخلی در حالت Standalone

**💡 مفهوم کلیدی**  
Tabbed App Bar یه قابلیت Chrome (نسخه 117+) هست که به PWA اجازه میده **تب‌های داخلی** داشته باشه — دقیقاً مثل مرورگر، ولی داخل خود اپ. وقتی کاربر لینک جدیدی رو باز می‌کنه، به جای باز شدن در مرورگر خارجی، **یه تب جدید داخل PWA** باز میشه. این یعنی تجربه‌ی کاملاً اپ‌مانند بدون خروج از اپ.

**⚠️ دام رایج**  
- فراموش کردن `tab_strip` در manifest (بدون اون فعال نمیشه!).
- عدم تنظیم `scope` درست (لینک‌های خارج از scope در مرورگر باز میشن).
- نادیده گرفتن `window-controls-overlay` که معمولاً همراه Tabbed App Bar استفاده میشه.
- عدم تست در نسخه‌های قدیمی Chrome (قبل از 117).
- فراموش کردن `display_override` (اگه `tab_strip` پشتیبانی نشه، fallback به standalone).
- عدم مدیریت `new_tab_url` (صفحه‌ی پیش‌فرض تب جدید).
- نادیده گرفتن اینکه این قابلیت **فقط در Chrome دسکتاپ** کار می‌کنه.

**📏 وضعیت پشتیبانی مرورگرها**

| مرورگر       | پشتیبانی | محدودیت                                  |
|--------------|-----------|-------------------------------------------|
| Chrome       | ✅        | نسخه 117+ + فقط دسکتاپ + origin trial    |
| Edge         | 🚧        | در حال بررسی                              |
| Safari       | ❌        | پشتیبانی نمیشه                            |
| Firefox      | ❌        | پشتیبانی نمیشه                            |
| موبایل       | ❌        | فقط دسکتاپ                                |

> ⚠️ **نکته حیاتی**: این قابلیت **فقط در Chrome دسکتاپ** (نسخه 117+) کار می‌کنه و هنوز در مرحله‌ی origin trial هست. همیشه fallback بذار!

**🛠️ راه‌حل سریع در کد**

### ۱. تنظیمات manifest.json

```json
// public/manifest.json
{
  "name": "فروشگاه من",
  "short_name": "فروشگاه",
  "start_url": "/?utm_source=pwa",
  "scope": "/",
  "display": "standalone",
  
  // ✅ fallback chain: اگه tab_strip پشتیبانی نشه، standalone استفاده میشه
  "display_override": ["tabbed", "window-controls-overlay", "standalone", "browser"],
  
  // ✅ تنظیمات Tabbed App Bar
  "tab_strip": {
    "new_tab_url": "/new-tab",
    "color_scheme": "light"
  },
  
  "background_color": "#ffffff",
  "theme_color": "#2563eb",
  "icons": [
    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    }
  ]
}
```

### ۴. هوک تشخیص حالت Tabbed

```jsx
// hooks/useDisplayMode.js
import { useState, useEffect } from 'react';

export function useDisplayMode() {
  const [displayMode, setDisplayMode] = useState('browser');

  useEffect(() => {
    const modes = [
      'tabbed',
      'window-controls-overlay',
      'standalone',
      'minimal-ui',
      'fullscreen',
      'browser',
    ];

    const checkMode = () => {
      for (const mode of modes) {
        if (window.matchMedia(`(display-mode: ${mode})`).matches) {
          setDisplayMode(mode);
          return;
        }
      }
      setDisplayMode('browser');
    };

    checkMode();

    // ✅ گوش دادن به تغییرات
    const mediaQueries = modes.map((mode) => {
      const mq = window.matchMedia(`(display-mode: ${mode})`);
      mq.addEventListener('change', checkMode);
      return mq;
    });

    return () => {
      mediaQueries.forEach((mq, i) => {
        mq.removeEventListener('change', checkMode);
      });
    };
  }, []);

  return {
    displayMode,
    isTabbed: displayMode === 'tabbed',
    isWindowControlsOverlay: displayMode === 'window-controls-overlay',
    isStandalone: displayMode === 'standalone',
    isInstalled: ['tabbed', 'window-controls-overlay', 'standalone', 'fullscreen', 'minimal-ui'].includes(displayMode),
  };
}
```

// components/AdaptiveHeader.jsx
import { useDisplayMode } from '@/hooks/useDisplayMode';

export function AdaptiveHeader() {

  if (isTabbed) {

}

### ۶. لینک‌ها و ناوبری در حالت Tabbed

```jsx
// components/SmartLink.jsx
import { useDisplayMode } from '@/hooks/useDisplayMode';

export function SmartLink({ href, children, ...props }) {
  const { isTabbed } = useDisplayMode();

  // ✅ در حالت tabbed، لینک‌های داخلی در تب جدید باز میشن
  // ✅ لینک‌های خارجی همیشه در مرورگر باز میشن
  const isExternal = href.startsWith('http') && !href.includes(window.location.hostname);

  if (isExternal) {
    return (
      <a href={href} target="_blank" rel="noopener noreferrer" {...props}>
        {children}
      </a>
    );
  }

  // ✅ لینک داخلی: در حالت tabbed، به صورت عادی (همون تب)
  return (
    <a href={href} {...props}>
      {children}
    </a>
  );
}
```

**🔗 ابزار تست**

- **Chrome 117+**: PWA رو نصب کن و ببین آیا تب‌ها ظاهر میشن.
- **Chrome DevTools** → Rendering → Emulate CSS media feature `display-mode: tabbed`.
- **Application** → Manifest → بررسی `tab_strip` و `display_override`.
- **Console**: `window.matchMedia('(display-mode: tabbed)').matches`.
- **Flags**: `chrome://flags/#desktop-pwas-tab-strip` رو فعال کن (اگه لازمه).
- **تست واقعی**: روی Chrome دسکتاپ 117+ نصب کن و تست کن.

> **قانون ۳ ثانیه‌ای:** PWA رو روی Chrome 117+ دسکتاپ نصب کن. آیا بالای اپ، نوار تب (مثل مرورگر) ظاهر میشه؟ یه لینک داخلی رو کلیک کن؛ آیا در تب جدید داخل اپ باز میشه؟ بعد DevTools → Rendering → `display-mode: tabbed` رو emulate کن؛ آیا CSS درست واکنش نشون میده؟ اگر نه، یعنی `tab_strip` در manifest درست تنظیم نشده!
