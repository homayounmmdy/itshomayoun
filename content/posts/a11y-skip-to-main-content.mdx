# 🎭  استفاده صحیح از ARIA (بدون زیاده‌روی!)

**💡 مفهوم کلیدی**  
ARIA (Accessible Rich Internet Applications) مجموعه‌ای از ویژگی‌هاست که برای *اضافه کردن* معنا به عناصر پیچیده‌ای استفاده میشه که HTML بومی (Native) به تنهایی از پسش برنمیاد. ARIA برای **جایگزین کردن** HTML بد نیست!

**⚠️ دام رایج (سندرم سوپ ARIA)**  
تبدیل یه `<div>` ساده به یه دکمه با اضافه کردن کوهی از ویژگی‌ها:
`<div role="button" aria-label="click" tabindex="0" onkeydown="...">`
**مشکل:** شما فقط ظاهر رو درست کردید، اما رفتارهای پیش‌فرض مرورگر (مثل کلیک با کلید Space، فوکوس رینگ استاندارد، و تاریخچه مرورگر) رو از دست دادید و کدتون رو ۱۰ برابر سنگین‌تر کردید.

**📏 قانون طلایی (The First Rule of ARIA)**  
> **اگر می‌توانید از یک تگ یا ویژگی HTML بومی (Native) استفاده کنید، از ARIA استفاده نکنید!**
- به جای `<div role="button">` ➡️ از `<button>` استفاده کنید.
- به جای `<div role="link">` ➡️ از `<a href="...">` استفاده کنید.
- به جای `<div role="img">` ➡️ از `<img alt="...">` استفاده کنید.

**🛠️ چه زمانی و چطور از ARIA استفاده کنیم؟**

### ۱. مخفی کردن آیکون‌های تزئینی (Decorative Icons)
وقتی یه آیکون کنار متن قرار می‌گیره، اسکرین‌ریدر نباید اون رو بخونه.
```jsx
// ❌ اشتباه: اسکرین‌ریدر می‌خونه "آیکون سطل آشغال، دکمه حذف"
<button> <TrashIcon /> حذف </button>

// ✅ درست: آیکون تزئینی رو از درخت دسترسی‌پذیری مخفی می‌کنیم
<button> <TrashIcon aria-hidden="true" /> حذف </button>
```

### ۲. نشان دادن وضعیت‌های پویا (مثل منوی آکاردئونی)
وقتی HTML بومی برای نشان دادن وضعیت "باز/بسته" بودن کافی نیست.
```jsx
// ✅ استفاده از aria-expanded برای نشان دادن وضعیت و aria-controls برای ارتباط
<button 
  aria-expanded={isOpen} 
  aria-controls="submenu-1"
>
  منوی محصولات
</button>
<ul id="submenu-1" hidden={!isOpen}>...</ul>
```

### ۳. لیبل‌های نامرئی (Invisible Labels)
وقتی طراحی UI اجازه نمیده تگ `<label>` رو روی صفحه نشون بدید، ولی اسکرین‌ریدر بهش نیاز داره.
```jsx
// ✅ استفاده از aria-label وقتی متن لیبل در DOM وجود نداره
<input type="search" aria-label="جستجو در سایت" placeholder="🔍" />
```

**🔗 ابزار تست و اعتبارسنجی**  
- افزونه مرورگر **Accessibility Insights** یا **axe DevTools** (بخش Automated checks).
- تست با اسکرین‌ریدر: `NVDA` (ویندوز) یا `VoiceOver` (مک).

> **قانون ۳ ثانیه‌ای:** قبل از اضافه کردن هر `role` یا `aria-*`، از خودت بپرس: «آیا یه تگ HTML ساده‌تر (مثل `<button>` یا `<nav>`) همین کار رو نمی‌کنه؟» اگر جواب بله بود، ARIA رو پاک کن!
