# ⏭️ لینک «پرش به محتوای اصلی» (Skip to Main Content)

**💡 مفهوم کلیدی**  
کاربرانی که با کیبورد یا اسکرین‌ریدر کار می‌کنن، مجبورن **هر بار** که به یه صفحه جدید میان، از بین ده‌ها لینک منو، لوگو، دکمه‌های شبکه‌های اجتماعی و... با Tab رد بشن تا به محتوای اصلی برسن. لینک Skip این مشکل رو با یه پرش مستقیم حل می‌کنه.

**⚠️ دام رایج**  
فکر کردن به اینکه "این لینک اضافیه و UI رو زشت می‌کنه" و کلاً حذفش کردن. یا پیاده‌سازی‌ای که فقط ظاهری هست و فوکوس رو واقعاً منتقل نمی‌کنه.

**📏 استاندارد WCAG (Success Criterion 2.4.1)**  
هر صفحه باید یه مکانیزم داشته باشه که کاربر بتونه بلوک‌های تکراری (مثل منوی اصلی) رو دور بزنه. این لینک **Level A** هست، یعنی **حداقلِ حداقلِ** دسترسی‌پذیری.

**🛠️ راه‌حل سریع در کد**

```jsx
// ۱. لینک رو به عنوان اولین عنصر قابل فوکوس در <body> قرار بده
<a
  href="#main-content"
  className="skip-link"
>
  پرش به محتوای اصلی
</a>

// ۲. محتوای اصلی رو با id مشخص کن
<main id="main-content" tabIndex={-1}>
  {/* محتوای صفحه */}
</main>
```

```css
/* ۳. استایل: مخفی تا زمانی که فوکوس بشه */
.skip-link {
  position: absolute;
  top: -100px;
  left: 0;
  background: #000;
  color: #fff;
  padding: 8px 16px;
  z-index: 9999;
  transition: top 0.2s;
}

.skip-link:focus {
  top: 8px; /* ✅ هنگام فوکوس با Tab ظاهر میشه */
}
```

**🔑 نکته‌ی کلیدی که خیلی‌ها فراموش می‌کنن**  
`tabIndex={-1}` روی `<main>` ضروریه! بدون اون، در بعضی مرورگرها (مخصوصاً Safari) بعد از کلیک روی Skip link، فوکوس واقعاً به `<main>` منتقل نمیشه و اسکرین‌ریدر هنوز از اول صفحه می‌خونه.

**🔗 ابزار تست**  
فقط کافیه توی صفحه‌ی خودت کلید **Tab** رو بزنی. اولین چیزی که باید ظاهر بشه، همین لینک Skip هست. اگر منو اول ظاهر شد، یعنی لینکت یا جاش اشتباهه یا `z-index` نداره.

> **قانون ۳ ثانیه‌ای:** صفحه رو باز کن، ماوس رو کنار بذار و فقط با Tab حرکت کن. اگر مجبور شدی بیشتر از ۵ بار Tab بزنی تا به محتوای اصلی برسی، یعنی Skip link نداری یا درست کار نمی‌کنه.
