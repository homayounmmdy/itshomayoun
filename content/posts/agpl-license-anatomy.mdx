# 🔒 کالبدشکافی مجوز AGPL v3: بستن حفره‌ی SaaS

## 💡 مفهوم کلیدی

مجوز AGPL v3 (GNU Affero General Public License) یعنی: **«همه‌ی حقوق GPLv3 رو داری، به‌اضافه یک قانون طلایی: اگه کد من رو روی سرور اجرا کنی و از طریق شبکه (مثل وب‌سایت یا API) به کاربرها سرویس بدی، باید کد منبع رو هم در اختیارشون بذاری.»** این لایسنس دقیقاً برای بستن حفره‌ای ساخته شد که در GPLv3 وجود داشت: شرکت‌ها کد GPL رو می‌گرفتن، تغییر می‌دادن، روی سرور اجرا می‌کردن و به عنوان SaaS می‌فروختن **بدون اینکه کد رو منتشر کنن** (چون "توزیع" نمی‌کردن!). AGPL این حفره رو می‌بنده.

## ⚠️ دام رایج

- ❌ فکر کردن به اینکه AGPL فقط یه GPLv3 با چند خط اضافه‌ست (تفاوت بنیادی: **Network Interaction**).
- ❌ استفاده از AGPL برای کتابخانه‌ای که قراره در اپ‌های کلاینت استفاده بشه (اینجا AGPL اضافی سفت‌گیرانه‌ست!).
- ❌ نادیده گرفتن بخش 13 که می‌گه "اگه کاربر بتونه از طریق شبکه با نرم‌افزار تعامل کنه، باید Source Code رو در دسترسش بذاری".
- ❌ فکر کردن به اینکه AGPL با GPLv3 ناسازگاره (برعکس! می‌تونی کد AGPL رو با GPLv3 ترکیب کنی).
- ❌ استفاده از AGPL برای پروژه‌ای که می‌خوای شرکت‌های بزرگ ازش استفاده کنن (خیلی‌ها از AGPL فرار می‌کنن!).
- ❌ فراموش کردن اینکه AGPL فقط برای "interaction over network" فعاله، نه برای هر استفاده‌ی داخلی.
- ❌ اضافه کردن محدودیت‌های اضافی به لایسنس AGPL (این کار لایسنس رو بی‌اعتبار می‌کنه!).
- ❌ عدم درک تفاوت بین "استفاده‌ی داخلی" (Internal Use) و "ارائه به عنوان سرویس" (SaaS).
- ❌ استفاده از AGPL برای پروژه‌ای که می‌خوای Dual License کنی (مدل تجاری پیچیده‌ای می‌سازه).
- ❌ فراموش کردن ارائه‌ی Source Code از طریق شبکه (مثلاً با یک endpoint مثل `/source`).

## 📏 مقایسه‌ی AGPL v3 با GPLv3 و Apache 2.0

| ویژگی | AGPL v3 | GPLv3 | Apache 2.0 |
|-------|---------|-------|-----------|
| استفاده تجاری | ✅ مجاز | ✅ مجاز | ✅ مجاز |
| تغییر و مشتق‌سازی | ✅ مجاز | ✅ مجاز | ✅ مجاز |
| توزیع مجدد | ✅ مجاز | ✅ مجاز | ✅ مجاز |
| حفظ کپی‌رایت | ⚠️ الزامی | ⚠️ الزامی | ⚠️ الزامی |
| Copyleft | ✅ **دارد** | ✅ **دارد** | ❌ ندارد |
| حفاظت از پتنت | ✅ دارد | ✅ دارد | ✅ دارد |
| Tivoization Prevention | ✅ دارد | ✅ دارد | ❌ ندارد |
| **Network Interaction (SaaS)** | ✅ **دارد** | ❌ **ندارد** | ❌ ندارد |
| ارائه‌ی Source Code در SaaS | ⚠️ **الزامی** | ❌ ندارد | ❌ ندارد |
| سازگاری با GPLv3 | ✅ سازگار | ✅ سازگار | ✅ سازگار |
| مناسب برای | SaaS, ابزارهای سروری | اپلیکیشن‌های دسکتاپ | پروژه‌های تجاری |
| مثال معروف | MongoDB (قدیم), Nextcloud, Grafana (قدیم) | Linux, GCC | Kubernetes, Android |

> ⚠️ **نکته حیاتی**: بخش 13 AGPL می‌گه: «اگه نرم‌افزار شما به کاربرها اجازه بده از طریق شبکه باهاش تعامل کنن، باید یک راه واضح برای دریافت Corresponding Source فراهم کنی.» این یعنی اگه یه API REST با AGPL داری، کاربرها باید بتونن کد منبعش رو دانلود کنن!

### 5. Endpoint برای ارائه‌ی Source Code (الزام AGPL)

```javascript
// src/server/source-endpoint.js
import express from 'express';
import fs from 'fs';
import path from 'path';
import { createGzip } from 'zlib';
import { pipeline } from 'stream/promises';

const router = express.Router();

// ✅ endpoint برای ارائه‌ی Source Code (الزام AGPL بخش 13)
router.get('/source', async (req, res) => {
  try {
    // ✅ مسیر Source Code
    const sourcePath = path.join(process.cwd(), 'source-code.tar.gz');
    
    // ❌ بررسی وجود فایل
    if (!fs.existsSync(sourcePath)) {
      return res.status(404).json({
        error: 'Source Code در دسترس نیست',
        message: 'لطفاً با maintainer تماس بگیرید',
      });
    }

    // ✅ ارسال فایل
    res.setHeader('Content-Type', 'application/gzip');
    res.setHeader('Content-Disposition', 'attachment; filename="source-code.tar.gz"');
    
    const fileStream = fs.createReadStream(sourcePath);
    await pipeline(fileStream, res);
    
    console.log('✅ Source Code ارائه شد');
  } catch (error) {
    console.error('❌ خطا در ارائه Source Code:', error);
    res.status(500).json({
      error: 'خطا در ارائه Source Code',
      message: error.message,
    });
  }
});

// ✅ صفحه‌ی اطلاعات لایسنس
router.get('/license', (req, res) => {
  res.json({
    license: 'AGPL-3.0',
    author: 'Homayoun Mohammadi',
    year: 2026,
    sourceCodeUrl: `${req.protocol}://${req.get('host')}/source`,
    licenseUrl: 'https://www.gnu.org/licenses/agpl-3.0.html',
    message: 'این نرم‌افزار تحت مجوز AGPL v3 منتشر شده است. شما حق دارید Source Code رو دریافت کنید.',
  });
});

export default router;
```

### 6. اسکریپت بررسی AGPL compliance

```javascript
// scripts/check-agpl-compliance.js
import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const AGPL_HEADER = `GNU Affero General Public License`;
const COPYRIGHT_PATTERN = /Copyright \(C\) \d{4} .+/;

function checkAGPLCompliance(dir) {
  const files = fs.readdirSync(dir);
  const violations = [];
  const checked = [];

  for (const file of files) {
    const filePath = path.join(dir, file);
    const stat = fs.statSync(filePath);

    if (stat.isDirectory()) {
      if (file !== 'node_modules' && !file.startsWith('.')) {
        const subResult = checkAGPLCompliance(filePath);
        violations.push(...subResult.violations);
        checked.push(...subResult.checked);
      }
    } else if (file.endsWith('.js') || file.endsWith('.ts') || file.endsWith('.jsx') || file.endsWith('.tsx')) {
      const content = fs.readFileSync(filePath, 'utf-8');
      checked.push(filePath);

      // ❌ بررسی وجود هدر AGPL
      if (!content.includes(AGPL_HEADER)) {
        violations.push({
          file: filePath,
          issue: '❌ هدر AGPL پیدا نشد',
        });
      }

      // ❌ بررسی وجود Copyright
      if (!COPYRIGHT_PATTERN.test(content)) {
        violations.push({
          file: filePath,
          issue: '❌ خط Copyright (C) پیدا نشد',
        });
      }
    }
  }

  return { violations, checked };
}

// ✅ بررسی وجود endpoint برای ارائه‌ی Source Code
function checkSourceEndpoint() {
  const serverFiles = fs.readdirSync(path.join(__dirname, '../src/server'));
  const hasSourceEndpoint = serverFiles.some(file => {
    const content = fs.readFileSync(path.join(__dirname, '../src/server', file), 'utf-8');
    return content.includes('/source') || content.includes('source-code');
  });

  if (!hasSourceEndpoint) {
    console.warn('⚠️ هشدار: endpoint برای ارائه‌ی Source Code پیدا نشد!');
    console.warn('   AGPL بخش 13 الزام می‌کنه که Source Code در دسترس باشه.');
  } else {
    console.log('✅ endpoint برای Source Code پیدا شد');
  }
}

// ✅ اجرای بررسی
const result = checkAGPLCompliance(path.join(__dirname, '../src'));

console.log(`\n📊 بررسی AGPL Compliance:`);
console.log(`   فایل‌های بررسی شده: ${result.checked.length}`);
console.log(`   نقض‌ها: ${result.violations.length}`);

if (result.violations.length > 0) {
  console.log('\n🚨 نقض‌های پیدا شده:');
  result.violations.forEach(v => {
    console.log(`   ${v.file}: ${v.issue}`);
  });
  process.exit(1);
} else {
  console.log('\n✅ تمام فایل‌ها با AGPL سازگار هستند!');
}

// ✅ بررسی endpoint
checkSourceEndpoint();
```
