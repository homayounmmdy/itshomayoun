# ⚡ PWA: بهینه‌سازی عملکرد و UX (راهنمای کامل)

**💡 مفهوم کلیدی**  
هفت تکنیک کلیدی برای ساخت یه PWA **فوق‌سریع** با **تجربه‌ی کاربری عالی**:
- **App Shell Model**: معماری برای لود اولیه‌ی سریع
- **Precaching**: ذخیره‌ی فایل‌های ضروری در install
- **Lazy Loading**: بارگذاری تنبل برای کاهش bundle size
- **Image Optimization**: فرمت‌های مدرن مثل WebP و AVIF
- **Resource Hints**: preconnect، prefetch، preload
- **Skeleton Screens**: placeholder برای perceived performance
- **Smooth Transitions**: انیمیشن‌های روان بین صفحات

این تکنیک‌ها تفاوت بین یه PWA **۱ ثانیه‌ای** و یه سایت **۱۰ ثانیه‌ای** هستن!

**⚠️ دام رایج**  
- بارگذاری همه‌چیز در initial bundle (bundle size بزرگ).
- عدم استفاده از App Shell (کاربر صفحه‌ی سفید می‌بینه).
- تصاویر بهینه‌نشده (۱۰ برابر حجم بیشتر).
- عدم prefetch برای صفحات بعدی.
- Skeleton Screen زشت یا گمراه‌کننده.
- انیمیشن‌های سنگین که `prefers-reduced-motion` رو نادیده می‌گیرن.
- فراموش کردن `loading="lazy"` برای تصاویر.
- عدم استفاده از `font-display: swap`.

**📏 جدول مقایسه تکنیک‌ها**

## 🏗️ بخش اول: App Shell Model

**💡 مفهوم:**  
App Shell یعنی **حداقل HTML/CSS/JS** که برای نمایش UI اولیه لازمه. کاربر اول shell رو می‌بینه (سریع!)، بعد محتوا از cache یا شبکه میاد.

### ۱. ساختار App Shell


### ۲. Precaching App Shell در Service Worker

```js
// public/sw.js

const SHELL_CACHE = 'app-shell-v1';
const SHELL_ASSETS = [
  '/',
  '/styles.css',
  '/app.js',
  '/fonts/vazir.woff2',
  '/icons/logo.svg',
];

// ✅ Install: precache کردن shell
self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(SHELL_CACHE).then((cache) => {
      console.log('[SW] Precaching app shell');
      return cache.addAll(SHELL_ASSETS);
    })
  );
  self.skipWaiting();
});

// ✅ Fetch: همیشه shell رو از cache برگردون (سریع!)
self.addEventListener('fetch', (event) => {
  if (event.request.mode === 'navigate') {
    event.respondWith(
      caches.match(event.request).then((cached) => {
        return cached || fetch(event.request);
      })
    );
  }
});
```

## 📦 بخش دوم: Precaching

**💡 مفهوم:**  
ذخیره‌ی فایل‌های ضروری **هنگام install** Service Worker، تا وقتی کاربر آنلاینه، همه‌چیز آماده باشه.

### ۳. Precaching با Workbox (توصیه‌شده)

```js
// public/sw.js
import { precacheAndRoute } from 'workbox-precaching';
import { registerRoute } from 'workbox-routing';
import { CacheFirst, NetworkFirst, StaleWhileRevalidate } from 'workbox-strategies';
import { ExpirationPlugin } from 'workbox-expiration';

// ✅ Precache کردن فایل‌های build شده
// این لیست توسط build tool (مثل webpack/vite) تولید میشه
precacheAndRoute(self.__WB_MANIFEST);

// ✅ Cache کردن تصاویر با Cache First
registerRoute(
  ({ request }) => request.destination === 'image',
  new CacheFirst({
    cacheName: 'images-cache',
    plugins: [
      new ExpirationPlugin({
        maxEntries: 100,
        maxAgeSeconds: 30 * 24 * 60 * 60, // ۳۰ روز
      }),
    ],
  })
);

// ✅ Cache کردن فونت‌ها
registerRoute(
  ({ request }) => request.destination === 'font',
  new CacheFirst({
    cacheName: 'fonts-cache',
    plugins: [
      new ExpirationPlugin({
        maxEntries: 10,
        maxAgeSeconds: 365 * 24 * 60 * 60, // ۱ سال
      }),
    ],
  })
);

// ✅ Cache کردن APIها با Network First
registerRoute(
  ({ url }) => url.pathname.startsWith('/api/'),
  new NetworkFirst({
    cacheName: 'api-cache',
    networkTimeoutSeconds: 3,
    plugins: [
      new ExpirationPlugin({
        maxEntries: 50,
        maxAgeSeconds: 5 * 60, // ۵ دقیقه
      }),
    ],
  })
);
```

## 🎯 بخش سوم: Lazy Loading

**💡 مفهوم:**  
بارگذاری کد و تصاویر **فقط وقتی لازم بشن** (وقتی کاربر بهشون نزدیک بشه).

### ۵. Lazy Loading تصاویر

```jsx
// ✅ روش ۱: Native lazy loading (ساده‌ترین)
<img 
  src="/product.jpg" 
  alt="محصول" 
  loading="lazy"
  width="400"
  height="300"
/>

// ✅ روش ۲: با Intersection Observer (کنترل بیشتر)
function LazyImage({ src, alt, placeholder = '/placeholder.svg' }) {
  const [imageSrc, setImageSrc] = useState(placeholder);
  const [loaded, setLoaded] = useState(false);
  const imgRef = useRef(null);

  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0].isIntersecting) {
          setImageSrc(src);
          observer.disconnect();
        }
      },
      { rootMargin: '200px' } // ✅ شروع لود ۲۰۰ پیکسل قبل از visible شدن
    );

    if (imgRef.current) {
      observer.observe(imgRef.current);
    }

    return () => observer.disconnect();
  }, [src]);

  return (
    <img
      ref={imgRef}
      src={imageSrc}
      alt={alt}
      onLoad={() => setLoaded(true)}
      className={`transition-opacity duration-300 ${loaded ? 'opacity-100' : 'opacity-50'}`}
    />
  );
}
```

### ۱۱. تبدیل تصاویر با Sharp

```js
// scripts/optimize-images.js
const sharp = require('sharp');
const fs = require('fs');
const path = require('path');

const inputDir = 'public/images/original';
const outputDir = 'public/images/optimized';

async function optimizeImages() {
  const files = fs.readdirSync(inputDir);

  for (const file of files) {
    const inputPath = path.join(inputDir, file);
    const name = path.parse(file).name;

    // ✅ WebP
    await sharp(inputPath)
      .webp({ quality: 80 })
      .toFile(path.join(outputDir, `${name}.webp`));

    // ✅ AVIF (بهترین کیفیت/حجم)
    await sharp(inputPath)
      .avif({ quality: 60 })
      .toFile(path.join(outputDir, `${name}.avif`));

    // ✅ Thumbnail برای placeholder
    await sharp(inputPath)
      .resize(20, 20, { fit: 'inside' })
      .blur(5)
      .toFile(path.join(outputDir, `${name}-thumb.jpg`));

    console.log(`✅ Optimized: ${file}`);
  }
}

optimizeImages();
```

### ۱۶. Prefetch هوشمند در React

```jsx
// hooks/usePrefetch.js
import { useEffect } from 'react';

export function usePrefetch(urls, trigger = 'hover') {
  useEffect(() => {
    const prefetch = () => {
      urls.forEach((url) => {
        const link = document.createElement('link');
        link.rel = 'prefetch';
        link.href = url;
        link.as = 'document';
        document.head.appendChild(link);
      });
    };

    if (trigger === 'hover') {
      // ✅ Prefetch وقتی کاربر روی لینک hover می‌کنه
      const links = document.querySelectorAll('[data-prefetch]');
      links.forEach((link) => {
        link.addEventListener('mouseenter', prefetch, { once: true });
      });
    } else if (trigger === 'idle') {
      // ✅ Prefetch وقتی مرورگر بیکاره
      if ('requestIdleCallback' in window) {
        requestIdleCallback(prefetch);
      } else {
        setTimeout(prefetch, 2000);
      }
    }
  }, [urls, trigger]);
}

// ✅ استفاده:
function ProductCard({ product }) {
  usePrefetch([`/products/${product.id}`], 'hover');

  return (
    <a 
      href={`/products/${product.id}`}
      data-prefetch
    >
      {product.name}
    </a>
  );
}
```

## 🎬 بخش هفتم: Smooth Transitions

**💡 مفهوم:**  
انیمیشن‌های روان بین صفحات برای احساس اپ‌مانند.

### ۲۱. Page Transitions در Next.js

```jsx
// ✅ با Framer Motion
'use client';

import { motion, AnimatePresence } from 'framer-motion';
import { usePathname } from 'next/navigation';

export function PageTransition({ children }) {
  const pathname = usePathname();

  return (
    <AnimatePresence mode="wait">
      <motion.div
        key={pathname}
        initial={{ opacity: 0, y: 20 }}
        animate={{ opacity: 1, y: 0 }}
        exit={{ opacity: 0, y: -20 }}
        transition={{ duration: 0.3, ease: 'easeInOut' }}
      >
        {children}
      </motion.div>
    </AnimatePresence>
  );
}

// ✅ استفاده در layout:
export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <PageTransition>{children}</PageTransition>
```

```jsx
// ✅ هوک برای تشخیص reduced motion
function useReducedMotion() {
  const [reduced, setReduced] = useState(false);

  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    setReduced(mq.matches);

    const handler = (e) => setReduced(e.matches);
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, []);

  return reduced;
}

// ✅ استفاده:
function AnimatedComponent() {
  const reducedMotion = useReducedMotion();

  return (
    <motion.div
      animate={reducedMotion ? {} : { y: [0, -10, 0] }}
      transition={{ duration: 2, repeat: Infinity }}
    >
      محتوا
    </motion.div>
  );
}
```
