# 🤖 PWA: انتشار در Google Play با TWA (Trusted Web Activity)

**💡 مفهوم کلیدی**  
**Trusted Web Activity (TWA)** یه قابلیت اندروید هست که به PWA اجازه میده **بدون address bar مرورگر** و به صورت **تمام‌صفحه** اجرا بشه - دقیقاً مثل یه اپ بومی! با TWA می‌تونی PWA رو به APK/AAB تبدیل کنی و در **Google Play** منتشر کنی.

**مزایای TWA:**
- دسترسی به ۳ میلیارد کاربر اندروید
- بدون نیاز به نوشتن کد Kotlin/Java
- آپدیت خودکار از طریق Google Play
- یکپارچگی با Notification، Badge، Shortcut
- اندازه‌ی بسیار کوچک (حدود ۵۰۰ KB)
- استفاده از Chrome engine (همیشه up-to-date)

**⚠️ دام رایج**  
- فراموش کردن `assetlinks.json` (بدون اون TWA کار نمی‌کنه و address bar نشون داده میشه!).
- عدم تطابق SHA-256 fingerprint با signing key.
- فراموش کردن `name` و `start_url` در manifest.
- عدم تست با `bubblewrap validate`.
- فراموش کردن `notifications` delegation.
- عدم تنظیم `display: standalone` در manifest.
- نادیده گرفتن `orientation` برای بازی‌ها.
- عدم استفاده از `PWABuilder` برای تولید خودکار.

**📏 پیش‌نیازها**

| مورد                          | توضیح                                              |
|-------------------------------|----------------------------------------------------|
| PWA با manifest معتبر         | name, short_name, icons, start_url, display: standalone |
| HTTPS                         | الزامی (به جز localhost برای تست)                 |
| Service Worker                | برای کار آفلاین                                   |
| Digital Asset Links           | فایل `assetlinks.json` روی سرور                   |
| Google Play Developer Account | هزینه‌ی یک‌باره: ۲۵ دلار                         |
| Bubblewrap یا PWABuilder      | ابزار بسته‌بندی                                   |
| JDK 11+                       | برای Bubblewrap                                   |
| Android Studio                | برای تست محلی (اختیاری)                           |

## 🔗 بخش اول: Digital Asset Links (حیاتی!)

### ۱. فایل assetlinks.json

این فایل **حیاتی‌ترین** بخش TWA هست. به گوگل می‌گه که "این وب‌سایت با این اپ اندروید مرتبطه".

```json
// /.well-known/assetlinks.json
[
  {
    "relation": ["delegate_permission/common.handle_all_urls"],
    "target": {
      "namespace": "android_app",
      "package_name": "com.example.myapp",
      "sha256_cert_fingerprints": [
        "14:6D:E9:83:C5:73:06:50:D8:EE:B9:95:2F:34:FC:64:16:A0:83:42:E6:1D:BE:A3:38:4C:F4:07:50:C2:7A:CC"
      ]
    }
  }
]
```

### ۲. دریافت SHA-256 Fingerprint

```bash
# ✅ روش ۱: از keystore فعلی
keytool -list -v -keystore my-release-key.keystore | grep SHA256

# ✅ روش ۲: از Google Play (بعد از آپلود)
# Google Play Console → App signing → App signing key → SHA-256

# ✅ روش ۳: با Bubblewrap
bubblewrap fingerprint
```

### ۳. بررسی صحت assetlinks.json

```bash
# ✅ بررسی آنلاین
curl https://example.com/.well-known/assetlinks.json

# ✅ باید Content-Type: application/json باشه
# ✅ باید HTTPS باشه
# ✅ نباید redirect داشته باشه
```

### ۴. Google Digital Asset Links API

```bash
# ✅ بررسی اینکه گوگل assetlinks رو درست می‌خونه
curl "https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://example.com"
```

### ۵. کامپوننت بررسی Digital Asset Links

```jsx
// components/DigitalAssetLinksCheck.jsx
import { useState, useEffect } from 'react';

export function DigitalAssetLinksCheck() {
  const [status, setStatus] = useState('checking');
  const [details, setDetails] = useState(null);

  useEffect(() => {
    const check = async () => {
      try {
        // ✅ بررسی فایل assetlinks.json
        const response = await fetch('/.well-known/assetlinks.json');
        
        if (!response.ok) {
          setStatus('error');
          setDetails({ message: 'فایل assetlinks.json پیدا نشد' });
          return;
        }

        const contentType = response.headers.get('content-type');
        if (!contentType?.includes('application/json')) {
          setStatus('error');
          setDetails({ message: 'Content-Type باید application/json باشه' });
          return;
        }

        const data = await response.json();
        
        if (!Array.isArray(data) || data.length === 0) {
          setStatus('error');
          setDetails({ message: 'فایل خالی یا نامعتبره' });
          return;
        }

        const firstEntry = data[0];
        
        if (!firstEntry.target?.sha256_cert_fingerprints?.length) {
          setStatus('error');
          setDetails({ message: 'SHA-256 fingerprint مشخص نشده' });
          return;
        }

        setStatus('success');
        setDetails({
          packageName: firstEntry.target.package_name,
          fingerprint: firstEntry.target.sha256_cert_fingerprints[0],
        });
      } catch (error) {
        setStatus('error');
        setDetails({ message: error.message });
      }
    };

    check();
  }, []);

  return (
    <div className={`p-6 rounded-lg border ${
      status === 'success' ? 'bg-green-50 border-green-200' :
      status === 'error' ? 'bg-red-50 border-red-200' :
      'bg-yellow-50 border-yellow-200'
    }`}>
      <h3 className="font-bold text-lg mb-2">
        {status === 'success' ? '✅ Digital Asset Links درست تنظیم شده' :
         status === 'error' ? '❌ خطا در Digital Asset Links' :
         '⏳ در حال بررسی...'}
      </h3>

      {details && (
        <div className="space-y-2 text-sm">
          {details.packageName && (
            <p><strong>Package Name:</strong> {details.packageName}</p>
          )}
          {details.fingerprint && (
            <p className="font-mono text-xs break-all">
              <strong>SHA-256:</strong> {details.fingerprint}
            </p>
          )}
          {details.message && (
            <p className="text-red-700">{details.message}</p>
          )}
        </div>
      )}
    </div>
  );
}
```

### ۱۹. کامپوننت TWA Debug

```jsx
// components/TWADebug.jsx
import { useState, useEffect } from 'react';

export function TWADebug() {
  const [info, setInfo] = useState(null);

  useEffect(() => {
    const checkTWA = async () => {
      const data = {
        isStandalone: window.matchMedia('(display-mode: standalone)').matches,
        isInstalled: window.matchMedia('(display-mode: standalone)').matches || 
                     window.navigator.standalone === true,
        userAgent: navigator.userAgent,
        isChrome: /Chrome/.test(navigator.userAgent),
        isAndroid: /Android/.test(navigator.userAgent),
        chromeVersion: navigator.userAgent.match(/Chrome\/(\d+)/)?.[1],
      };

      setInfo(data);

      // ✅ بررسی assetlinks.json
      try {
        const response = await fetch('/.well-known/assetlinks.json');
        data.assetLinksStatus = response.ok ? '✅ موجود' : '❌ ناموجود';
      } catch {
        data.assetLinksStatus = '❌ خطا';
      }

      setInfo({ ...data });
    };

    checkTWA();
  }, []);

  if (!info) return <p>در حال بررسی...</p>;

  return (
    <div className="p-6 bg-gray-50 rounded-lg space-y-3 font-mono text-sm">
      <h3 className="font-bold text-lg">🔍 TWA Debug Info</h3>
      <div className="space-y-1">
        <p>Display Mode: {info.isStandalone ? '✅ standalone' : '❌ browser'}</p>
        <p>Installed: {info.isInstalled ? '✅' : '❌'}</p>
        <p>Platform: {info.isAndroid ? 'Android' : 'Other'}</p>
        <p>Browser: {info.isChrome ? `Chrome ${info.chromeVersion}` : 'Other'}</p>
        <p>Asset Links: {info.assetLinksStatus}</p>
      </div>
    </div>
  );
}
```

### ۲۳. هوک تشخیص TWA

```jsx
// hooks/useIsTWA.js
import { useState, useEffect } from 'react';

export function useIsTWA() {
  const [isTWA, setIsTWA] = useState(false);

  useEffect(() => {
    const check = () => {
      // ✅ بررسی display-mode: standalone
      const isStandalone = window.matchMedia('(display-mode: standalone)').matches;
      
      // ✅ بررسی user agent (TWA معمولاً Chrome engine داره)
      const isChrome = /Chrome/.test(navigator.userAgent);
      const isAndroid = /Android/.test(navigator.userAgent);
      
      setIsTWA(isStandalone && isChrome && isAndroid);
    };

    check();
  }, []);

  return isTWA;
}

// ✅ استفاده:
function App() {
  const isTWA = useIsTWA();
  
  return (
    <div>
      {isTWA ? (
        <p>🤖 در حال اجرای TWA</p>
      ) : (
        <p>🌐 در حال اجرای وب</p>
      )}
    </div>
  );
}
```

**🔗 ابزار تست و انتشار**

- **[PWABuilder](https://www.pwabuilder.com/)**: ابزار ساده برای بسته‌بندی
- **[Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap)**: CLI tool حرفه‌ای
- **[Google Play Console](https://play.google.com/console)**: داشبورد مدیریت Store
- **[Digital Asset Links API](https://developers.google.com/digital-asset-links/v1/getting-started)**: بررسی assetlinks
- **[TWA Quality Checklist](https://developer.chrome.com/docs/android/trusted-web-activity/quality-criteria/)**: چک‌لیست کیفیت
- **adb**: برای تست محلی
- **Android Studio**: برای دیباگ پیشرفته

**⚠️ چک‌لیست نهایی**

**آماده‌سازی PWA:**
- [ ] manifest.json معتبر با display: standalone؟
- [ ] آیکون‌های 192 و 512 موجودن؟
- [ ] Service Worker ثبت شده؟
- [ ] سایت روی HTTPS هست؟

**Digital Asset Links:**
- [ ] فایل assetlinks.json در /.well-known/ قرار گرفته؟
- [ ] Content-Type: application/json هست؟
- [ ] SHA-256 fingerprint درست تنظیم شده؟
- [ ] package_name با اپ یکیه؟
- [ ] با curl تست شده؟

**بسته‌بندی:**
- [ ] با Bubblewrap یا PWABuilder بسته‌بندی کردی؟
- [ ] versionCode و versionName درست تنظیم شدن؟
- [ ] Keystore امن نگه‌داری شده؟
- [ ] APK محلی تست شده؟

**تست:**
- [ ] address bar نشون داده نمیشه؟
- [ ] Notification کار می‌کنه؟
- [ ] Shortcut کار می‌کنه؟
- [ ] کار آفلاین تست شده؟

**Google Play:**
- [ ] حساب Developer ثبت شده؟
- [ ] Privacy Policy آماده‌ست؟
- [ ] Screenshots با کیفیت داری؟
- [ ] Data Safety Form تکمیل شده؟
- [ ] Content Rating پر شده؟

> **قانون ۳ ثانیه‌ای:** APK رو روی دستگاه اندروید نصب کن و باز کن. آیا address bar مرورگر نشون داده میشه؟ اگه بله، یعنی assetlinks.json مشکل داره! بعد `adb shell pm get-app-links com.example.myapp` رو اجرا کن؛ باید `verified` نشون بده. اگه `none` یا `legacy_failure` بود، یعنی SHA-256 fingerprint اشتباهه!
