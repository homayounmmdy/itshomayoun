# 👥 PWA: Contact Picker API و انتخاب مخاطب از دفترچه تلفن

**💡 مفهوم کلیدی**  
Contact Picker API به سایت اجازه میده **پنجره‌ی انتخاب مخاطب** بومی دستگاه رو باز کنه. کاربر خودش انتخاب می‌کنه کدوم مخاطب رو به اشتراک بذاره و سایت **فقط همون اطلاعات** رو می‌گیره. این یعنی **حریم خصوصی کامل** (برخلاف دسترسی کامل به دفترچه تلفن).

**⚠️ دام رایج**  
- درخواست دسترسی بدون user gesture (مرورگر بلاک می‌کنه).
- فراموش کردن بررسی پشتیبانی مرورگر.
- درخواست همه‌ی فیلدها وقتی فقط به ایمیل نیاز داری.
- عدم مدیریت خطا (کاربر انصراف بده).
- استفاده در دسکتاپ (پشتیبانی نمیشه).
- عدم احترام به حریم خصوصی کاربر.

**📏 وضعیت پشتیبانی مرورگرها (خیلی محدود!)**

| مرورگر       | پشتیبانی | محدودیت                                  |
|--------------|-----------|-------------------------------------------|
| Chrome       | ✅        | **فقط Android** + نیاز به HTTPS           |
| Edge         | ✅        | فقط Android                               |
| Opera        | ✅        | فقط Android                               |
| Safari       | ❌        | **پشتیبانی نمیشه**                        |
| iOS Safari   | ❌        | پشتیبانی نمیشه                            |
| Firefox      | ❌        | پشتیبانی نمیشه                            |
| دسکتاپ       | ❌        | پشتیبانی نمیشه                            |

> ⚠️ **نکته حیاتی**: این API فقط در **Chrome Android** کار می‌کنه. همیشه fallback بذار!

**🛠️ راه‌حل سریع در کد**

### ۱. هوک React برای مدیریت Contact Picker

```jsx
// hooks/useContactPicker.js
import { useState, useCallback } from 'react';

export function useContactPicker() {
  const [contacts, setContacts] = useState([]);
  const [error, setError] = useState(null);
  const [isSupported, setIsSupported] = useState(false);

  // ✅ بررسی پشتیبانی
  useState(() => {
    setIsSupported('contacts' in navigator && 'ContactsManager' in window);
  }, []);

  // ✅ انتخاب مخاطب
  const pickContact = useCallback(async (properties = ['name', 'email']) => {
    if (!isSupported) {
      setError('Contact Picker در این مرورگر پشتیبانی نمیشه');
      return null;
    }

    try {
      // ✅ باز کردن پنجره انتخاب مخاطب
      const selectedContacts = await navigator.contacts.select(properties, {
        multiple: true, // اجازه انتخاب چند مخاطب
      });

      setContacts(selectedContacts);
      setError(null);
      return selectedContacts;
    } catch (err) {
      if (err.name === 'AbortError') {
        // ✅ کاربر انصراف داد
        setError(null);
        return null;
      }
      setError(err.message);
      return null;
    }
  }, [isSupported]);

  // ✅ پاک کردن مخاطبین انتخاب‌شده
  const clearContacts = useCallback(() => {
    setContacts([]);
    setError(null);
  }, []);

  return {
    isSupported,
    contacts,
    error,
    pickContact,
    clearContacts,
  };
}
```

### ۲. کامپوننت انتخاب مخاطب

```jsx
// components/ContactPicker.jsx
import { useContactPicker } from '@/hooks/useContactPicker';

export function ContactPicker({ onSelect }) {
  const { isSupported, contacts, error, pickContact } = useContactPicker();

  const handlePick = async () => {
    // ✅ فقط نام و ایمیل رو درخواست کن (نه شماره تلفن)
    const selected = await pickContact(['name', 'email']);
    if (selected) {
      onSelect?.(selected);
    }
  };

  if (!isSupported) {
    return (
      <div className="p-4 bg-yellow-50 border border-yellow-200 rounded-lg">
        <p className="text-sm text-yellow-800">
          ⚠️ انتخاب مخاطب از دفترچه تلفن فقط در Chrome Android پشتیبانی میشه.
        </p>
      </div>
    );
  }

  return (
    <div className="space-y-4">
      <button
        onClick={handlePick}
        className="w-full bg-blue-600 text-white px-6 py-3 rounded-lg 
                   hover:bg-blue-700 transition-colors font-medium
                   flex items-center justify-center gap-2"
      >
        <svg className="w-5 h-5" fill="none" viewBox="0 0 24 24" stroke="currentColor" aria-hidden="true">
          <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M17 20h5v-2a3 3 0 00-5.356-1.857M17 20H7m10 0v-2c0-.656-.126-1.283-.356-1.857M7 20H2v-2a3 3 0 015.356-1.857M7 20v-2c0-.656.126-1.283.356-1.857m0 0a5.002 5.002 0 019.288 0M15 7a3 3 0 11-6 0 3 3 0 016 0zm6 3a2 2 0 11-4 0 2 2 0 014 0zM7 10a2 2 0 11-4 0 2 2 0 014 0z" />
        </svg>
        انتخاب از مخاطبین
      </button>

      {error && (
        <div role="alert" className="p-3 bg-red-50 border border-red-200 rounded-lg">
          <p className="text-sm text-red-800">{error}</p>
        </div>
      )}
    </div>
  );
}
```

### ۳. استفاده در فرم دعوت

```jsx
// components/InviteForm.jsx
import { useState } from 'react';
import { ContactPicker } from './ContactPicker';

export function InviteForm() {
  const [invitedContacts, setInvitedContacts] = useState([]);
  const [message, setMessage] = useState('');

    setInvitedContacts(contacts);
  };

  const handleInvite = async () => {
    const emails = invitedContacts
      .flatMap(c => c.email || [])
      .filter(Boolean);

    if (emails.length === 0) {
      alert('لطفاً حداقل یک مخاطب با ایمیل انتخاب کنید');
      return;
    }

    try {
      await sendInvites(emails, message);
      alert(`${emails.length} دعوت‌نامه ارسال شد`);
    } catch (error) {
      alert('خطا در ارسال دعوت‌نامه');
    }
  };

  return (
    <div className="max-w-md mx-auto p-6 space-y-6">
      <h2 className="text-2xl font-bold">دعوت از دوستان</h2>

      {/* ✅ انتخاب مخاطب */}
      <ContactPicker onSelect={handleContactSelect} />

      {/* ✅ نمایش مخاطبین انتخاب‌شده */}
      {invitedContacts.length > 0 && (
        <div className="space-y-2">
          <p className="font-medium">مخاطبین انتخاب‌شده:</p>
          <ul className="space-y-1">
            {invitedContacts.map((contact, idx) => (
              <li key={idx} className="p-2 bg-gray-50 rounded flex items-center gap-2">
                <span className="font-medium">{contact.name?.[0] || 'بدون نام'}</span>
                {contact.email?.[0] && (
                  <span className="text-sm text-gray-600">({contact.email[0]})</span>
                )}
              </li>
            ))}
          </ul>
        </div>
      )}

      {/* ✅ پیام دعوت */}
      <div>
        <label htmlFor="message" className="block text-sm font-medium mb-2">
          پیام دعوت (اختیاری)
        </label>
        <textarea
          id="message"
          value={message}
          onChange={(e) => setMessage(e.target.value)}
          className="w-full p-3 border border-gray-300 rounded-lg"
          rows={3}
          placeholder="به اپ ما بپیوندید!"
        />
      </div>

      {/* ✅ دکمه ارسال */}
      <button
        onClick={handleInvite}
        disabled={invitedContacts.length === 0}
        className="w-full bg-green-600 text-white px-6 py-3 rounded-lg 
                   hover:bg-green-700 transition-colors font-medium
                   disabled:bg-gray-300 disabled:cursor-not-allowed"
      >
        ارسال دعوت‌نامه ({invitedContacts.length} نفر)
      </button>
    </div>
  );
}
```

### ۵. Fallback برای مرورگرهای بدون پشتیبانی

```jsx
// components/ContactPickerWithFallback.jsx
import { useState } from 'react';
import { ContactPicker } from './ContactPicker';

export function ContactPickerWithFallback({ onSelect }) {
  const [manualEmail, setManualEmail] = useState('');

  const handleManualAdd = () => {
    if (manualEmail) {
      onSelect?.([{ name: [''], email: [manualEmail] }]);
      setManualEmail('');
    }
  };

  return (
    <div className="space-y-4">
      {/* ✅ Contact Picker (اگر پشتیبانی بشه) */}
      <ContactPicker onSelect={onSelect} />

      {/* ✅ Fallback: ورودی دستی */}
      <div className="border-t pt-4">
        <p className="text-sm text-gray-600 mb-2">یا ایمیل رو دستی وارد کنید:</p>
        <div className="flex gap-2">
          <input
            type="email"
            value={manualEmail}
            onChange={(e) => setManualEmail(e.target.value)}
            placeholder="example@email.com"
            className="flex-1 p-2 border border-gray-300 rounded"
          />
          <button
            onClick={handleManualAdd}
            className="bg-gray-200 px-4 py-2 rounded hover:bg-gray-300"
          >
            افزودن
          </button>
        </div>
      </div>
    </div>
  );
}
```

**🔗 ابزار تست**

- **Chrome Android**: سایت رو روی موبایل اندروید با Chrome باز کن.
- **DevTools** → Console: `navigator.contacts` باید وجود داشته باشه.
- **تست واقعی**: دکمه رو بزن، پنجره انتخاب مخاطب باید باز بشه.
- **Safari/iOS**: تست کن که fallback درست کار می‌کنه.
- **دسکتاپ**: تست کن که پیام "پشتیبانی نمیشه" نشون داده بشه.

**⚠️ چک‌لیست نهایی**

- [ ] بررسی پشتیبانی مرورگر قبل از استفاده؟
- [ ] استفاده فقط در response به user gesture؟
- [ ] درخواست فقط فیلدهای ضروری (نه همه‌چیز)؟
- [ ] مدیریت خطای AbortError (انصراف کاربر)؟
- [ ] Fallback برای مرورگرهای بدون پشتیبانی؟
- [ ] نمایش واضح اطلاعات انتخاب‌شده به کاربر؟
- [ ] احترام به حریم خصوصی (عدم ذخیره بدون اجازه)؟
- [ ] تست در Chrome Android واقعی؟
- [ ] تست در Safari/iOS (fallback)؟

> **قانون ۳ ثانیه‌ای:** سایت رو روی Chrome Android باز کن، دکمه "انتخاب از مخاطبین" رو بزن. آیا پنجره بومی انتخاب مخاطب باز میشه؟ بعد Safari رو باز کن؛ آیا fallback (ورودی دستی) نشون داده میشه؟ اگر نه، یعنی API رو درست پیاده‌سازی نکردی!
