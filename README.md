# وبلاگ شخصی همایون (It's Homayoun) 🚀

این ریپو مربوط به وبلاگ شخصی من است. در این وبلاگ تجربیات، مقالات و یادداشت‌های خود را در حوزه‌های برنامه‌نویسی، تکنولوژی و روزمرگی به اشتراک می‌گذارم.

🌐 **آدرس وبلاگ:** [http://itshomayoun.vercel.app/](http://itshomayoun.vercel.app/)

## ✨ ویژگی‌ها و تکنولوژی‌های استفاده شده

این وبلاگ با استفاده از قالب **Nextra Blog Template** پیاده‌سازی شده است تا تجربه‌ای سریع، مدرن و بهینه برای نوشتن و خواندن مقالات فراهم کند. تکنولوژی‌های اصلی به کار رفته در این پروژه عبارتند از:

* ⚡ **Next.js** - فریم‌ورک قدرتمند ری‌اکت برای رندرینگ ترکیبی (SSG/SSR).
* 📖 **Nextra** - ابزاری فوق‌العاده بر پایه Next.js برای ساخت وبلاگ‌ها و مستندات با استفاده از MDX.
* ⚛️ **React** - برای ایجاد رابط کاربری پویا و کامپوننت‌محور.
* ✍️ **MDX** - ترکیب قدرت Markdown و JSX برای نوشتن مقالات تعاملی.
* 🎨 **Tailwind CSS** - برای استایل‌دهی سریع، کاربردی و ریسپانسیو.
* ▲ **Vercel** - برای میزبانی، استقرار (Deployment) و شبکه توزیع محتوا (CDN) با سرعت بالا.

## 🛠 راه‌اندازی و اجرای لوکال (Local Development)

اگر تمایل دارید این پروژه را روی سیستم خود اجرا کنید یا تغییراتی در آن ایجاد کنید، مراحل زیر را دنبال نمایید:

### پیش‌نیازها
* نصب بودن **Node.js** (نسخه 18 یا بالاتر پیشنهاد می‌شود)
* نصب بودن **Git**
* یکی از پکیج‌منیجرهای `npm`، `yarn` یا `pnpm`

### مراحل اجرا

۱. ابتدا ریپو پروژه را کلون کنید:
```bash
git clone https://github.com/your-username/its-homayoun-blog.git
cd its-homayoun-blog
```

۲. پکیج‌های مورد نیاز پروژه را نصب کنید:
```bash
npm install
# یا
yarn install
# یا
pnpm install
```

۳. سرور توسعه (Development Server) را اجرا کنید:
```bash
npm run dev
# یا
yarn dev
# یا
pnpm dev
```

اکنون می‌توانید وبلاگ را در مرورگر خود از طریق آدرس [http://localhost:3000](http://localhost:3000) مشاهده کنید. تغییرات در کدها و مقالات به صورت خودکار (Hot Reload) اعمال می‌شوند.
